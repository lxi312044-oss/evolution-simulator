# Phase 07.2.25 — Extreme toxin strength sweep

## Purpose
Test whether toxin resistance increases across generations under strong toxin pressure, without assuming that stronger toxin necessarily increases selection.

## Fixed scope
- Same toxin model and resistance inheritance; only toxin HP damage coefficient changes.
- Conditions: toxin OFF control, x1, x2, x4, x10, x20, x50.
- Seeds 12345–12364, 50,000 ticks, 100-tick observations, spontaneous germination p=0.005 (soil threshold 20, interval 20, max births 20).
- Fixes the `args.len()==10` mistake in `resistance_life_07222.rs`; the program takes 11 arguments including executable name. Previous Phase 07.2.22 runs DID NOT enable germination through this path.
- Does not alter ecological rules otherwise.

## Acceptance criteria
1. `cargo test --workspace` succeeds.
2. `tools/run_phase07225.ps1 -DryRun` lists all 140 planned runs.
3. All run summaries pass validation, and report resistance change, extinction, births, and survival.
4. Never interpret missing resistance mean after extinction as zero resistance.
5. Selection inference must distinguish resistance gain from demographic collapse; further cohort-matched analysis may be required.

## Execution
```
cargo test --workspace
.\tools\run_phase07225.ps1 -DryRun
.\tools\run_phase07225.ps1
```

For quick screening first: `.\tools\run_phase07225.ps1 -SeedCount 3 -Ticks 10000 -Multipliers @(0,4,10,20,50)`; use a separate results directory or remove screening results before the full run to avoid accidentally mixing horizons.

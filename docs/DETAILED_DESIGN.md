# 毒・色・攻撃による生物進化シミュレーション

対象：植物・草食動物・肉食動物｜2Dシミュレーション｜遺伝＋学習型AI

## 第1章　システム概要

### 1.1 目的

本システムは、植物・草食動物・肉食動物が存在する仮想生態系において、毒・抗体・体色・攻撃能力・学習能力が生存と繁殖に与える影響を観察するシミュレーションである。

特に、次の現象が自然に発生する可能性を持つことを目的とする。

- 有毒生物の警告色
- 無毒生物による有毒生物への擬態
- 毒と抗体の進化的競争
- 捕食者の経験による色への警戒・選好
- 空腹による危険な捕食行動
- 攻撃性と慎重さの自然選択

これらの現象を強制的に発生させるイベントは実装しない。

### 1.2 実装範囲

| 項目   | 実装方針              |
| ---- | ----------------- |
| 植物   | 発生・成長・種子散布・死亡     |
| 草食動物 | 移動・植物や死体の捕食・攻撃・繁殖 |
| 肉食動物 | 移動・動物や死体の捕食・攻撃・繁殖 |
| 色    | RGBで保持、OKLabで認識   |
| 学習   | 色と経験の関連付け         |
| 遺伝   | 親の遺伝子を継承          |
| 突然変異 | 数値変異・低確率の種類変異     |
| 毒    | 捕食毒・攻撃毒           |
| 抗体   | 毒の種類ごとの耐性         |
| 行動AI | 個体単位のUtility AI   |
| 移動   | ランダム移動・直線追跡・直線逃走  |
| 群れ   | 実装しない             |

### 1.3 基本原則

生物は自分の生存に必要な情報を完全には把握できない。

例えば、動物は相手の色や大きさは観測できるが、相手の毒の種類・正確な攻撃力・抗体などは直接参照できない。

相手の危険性は、遺伝的な判断傾向と過去の経験から推測する。

## 第2章　世界と時間

### 2.1 世界の定義

世界は2D連続座標を使用する。

| パラメータ        | 初期値  |
| ------------ | ---- |
| worldWidth   | 1000 |
| worldHeight  | 1000 |
| tickDuration | 1.0  |
| 初期植物数        | 300  |
| 初期草食動物数      | 80   |
| 初期肉食動物数      | 20   |
| 最大個体数        | 5000 |
| 土地セルサイズ      | 20   |

世界座標は0〜1000とし、1 Tickをシミュレーション上の1秒とする。

描画FPSとシミュレーションTickは独立させる。

### 2.2 土地

土地は20×20単位のセルに分割する。

各セルには以下を保持する。

```
record LandCell(
    int x,
    int y,
    double fertility,
    double nutrients
) {}
```

- `fertility`：土地の基本的な肥沃度（0〜1）
- `nutrients`：利用可能な栄養量（0以上）

植物の発生率と成長速度は、肥沃度および栄養量によって変化する。

死体が分解されると栄養量が増加する。

## 第3章　データモデル

### 3.1 生物共通モデル

```
abstract class Organism {
    long id;
    int speciesId;
    int generation;

    Vector2 position;
    ColorRGB color;

    double age;
    double hp;
    double maxHp;
    double growth;

    List<ToxinTrait> toxins;
    List<AntibodyTrait> antibodies;

    boolean alive;
}
```

植物・動物の双方がこのモデルを継承する。

`growth` は0〜1とする。

HPが0以下になった生物は死亡し、死体へ変換する。

### 3.2 植物モデル

```
class Plant extends Organism {
    PlantGenome genome;

    double energy;
    double seedCooldown;
}
```

植物は移動しない。

植物の行動は次の3つとする。

1. 栄養を消費して成長する。
2. 成熟後、条件を満たせば種子を散布する。
3. HPが0になれば死亡する。

植物は攻撃しないが、捕食毒を保有できる。

### 3.3 動物モデル

```
class Animal extends Organism {
    AnimalGenome genome;
    AnimalMemory memory;

    DietType diet;
    AnimalState state;

    double energy;
    double hunger;

    double attack;
    double defense;
    double speed;

    double visionRange;
    double attackRange;

    long targetId;
    double attackCooldown;
    double reproductionCooldown;

    List<PoisonEffect> activePoisonEffects;
}
```

`DietType` は次の値を持つ。

```
enum DietType {
    HERBIVORE,
    CARNIVORE
}
```

食性は対象選択の制約に使用する。

草食動物は植物、肉食動物は動物を主な捕食対象とする。死体は両者とも摂取可能とする。

ただし、肉食動物が生きた植物を食べたり、草食動物が生きた動物を食べたりすることは初期実装では許可しない。

### 3.4 死体モデル

```
class Corpse {
    long id;
    Vector2 position;
    ColorRGB color;

    double nutrients;
    double decay;
    double maxDecay;

    List<ToxinTrait> toxins;
}
```

死体は元の生物とは別のオブジェクトとして管理する。

死体は攻撃・移動・繁殖を行わない。

死体を食べた場合、残存栄養量が減少する。完全に分解された場合は土地に栄養を還元する。

## 第4章　遺伝子モデル

### 4.1 遺伝子の構成

動物の遺伝子は以下に分割する。

```
class AnimalGenome {
    BodyGenes body;
    ColorGenes color;
    CombatGenes combat;
    ToxinGenes toxin;
    AntibodyGenes antibody;
    BehaviorGenes behavior;
    CognitionGenes cognition;
    ReproductionGenes reproduction;
}
```

各遺伝子の責務を明確に分け、将来の拡張時に既存の遺伝子構造への影響を抑える。

### 4.2 身体・戦闘遺伝子

| 属性              | 初期範囲        |
| --------------- | ----------- |
| maxHpGene       | 20〜200      |
| attackGene      | 1〜40        |
| defenseGene     | 0〜20        |
| speedGene       | 0.5〜8       |
| visionRangeGene | 20〜150      |
| attackRangeGene | 2〜15        |
| growthRateGene  | 0.0001〜0.01 |

実際の能力値は成長度によって補正する。

例えば攻撃力は以下とする。

\\[ Attack=AttackGene(0.3+0.7Growth) \\]

最大HPも同じ成長補正を使用する。

成長によって最大HPが増加しても、現在HPが自動的に全回復するわけではない。

最大HP増加分の一定割合を現在HPへ追加する。

### 4.3 行動遺伝子

| 属性                 | 範囲  | 説明          |
| ------------------ | --- | ----------- |
| aggression         | 0〜1 | 攻撃性         |
| riskTolerance      | 0〜1 | 基本危険許容度     |
| hungerDesperation  | 0〜1 | 空腹による危険許容   |
| victoryConfidence  | 0〜1 | 勝利経験の重視度    |
| toxinTolerance     | 0〜1 | 毒による損害の許容傾向 |
| retreatSensitivity | 0〜1 | 逃走しやすさ      |
| explorationRate    | 0〜1 | 未知の対象への接近傾向 |

`toxinTolerance` は行動上の性格であり、実際の毒ダメージを減少させない。

毒ダメージを減少させるのは抗体である。

## 第5章　連続色認識

### 5.1 色データ

体色はRGBの各成分を0〜1で保持する。

```
record ColorRGB(
    double r,
    double g,
    double b
) {}
```

色の類似度計算にはOKLabを使用する。

RGBからOKLabへの変換は、sRGBのガンマ補正解除を行ってから標準の変換式を適用する。

### 5.2 色の距離

\\[ d(c_1,c_2)= \sqrt{(L_1-L_2)^2+(a_1-a_2)^2+(b_1-b_2)^2} \\]

### 5.3 色の類似度

\\[ K(c_1,c_2)= \exp\left(-\frac{d(c_1,c_2)^2}{2\sigma^2}\right) \\]

\\(\sigma\\) は遺伝子で決まる色の一般化幅とする。

値が小さいほど近い色のみを同じものとして扱う。

### 5.4 色認識の処理

```
対象を視認
    ↓
RGBを取得
    ↓
OKLabへ変換
    ↓
記憶色との距離を計算
    ↓
危険度・食料価値・勝利期待値を予測
    ↓
意思決定AIへ渡す
```

初期実装では、索敵範囲内の対象の色は正確に認識できるものとする。

背景への擬態、視認誤差、遮蔽物は拡張機能とする。

## 第6章　記憶と学習

### 6.1 記憶データ

```
record ColorMemoryEntry(
    ColorRGB color,
    double attackDanger,
    double toxinDanger,
    double foodValue,
    double winProbability,
    double captureDifficulty,
    double confidence,
    double timestamp
) {}
```

記憶は個体ごとに保持する。

初期記憶容量は30件とする。

### 6.2 記憶からの予測

色 \\(c\\) に対する評価値を次の式で計算する。

\\[ V(c)= \frac{\lambda V_0(c)+\sum_i K(c,c_i)q_iV_i} {\lambda+\sum_i K(c,c_i)q_i} \\]

ここで、

- \\(V_0(c)\\)：遺伝による初期評価
- \\(\lambda\\)：先天的判断の重み
- \\(V_i\\)：経験した評価値
- \\(q_i\\)：記憶の信頼度
- \\(K\\)：色類似度

とする。

危険度・食料価値・勝利期待値などは、この式を個別に適用する。

### 6.3 学習更新

経験による評価値の更新には以下を使用する。

\\[ V\_{\mathrm{new}} = V\_{\mathrm{old}} +\alpha(R-V\_{\mathrm{old}}) \\]

\\(\alpha\\) は遺伝的な学習率、\\(R\\) は経験結果を0〜1へ正規化した値である。

例えば、戦闘で勝利した場合は勝利期待値の学習目標を1、敗北した場合は0とする。

毒による危険度は、実際に受けた毒ダメージを自身の最大HPで正規化して更新する。

\\[ R\_{\mathrm{toxin}} = \operatorname{clamp} \left( \frac{D\_{\mathrm{toxin}}}{MaxHP}, 0,1 \right) \\]

### 6.4 記憶の忘却

\\[ q(t)=q_0e^{-\beta t} \\]

\\(\beta\\) は遺伝的な忘却率とする。

記憶の信頼度が一定値を下回った場合、削除候補とする。

### 6.5 記憶の統合

新しい経験の色に最も近い記憶を探索する。

類似度が0.9以上なら既存記憶へ統合する。

それ未満なら新規記憶として追加する。

記憶容量を超えた場合は、信頼度と新しさから算出した重要度が最も低い記憶を削除する。

### 6.6 学習と遺伝の関係

経験によって変化した記憶は子に継承しない。

子は親の遺伝子を継承するが、記憶は空の状態で生まれる。

ただし、遺伝子に含まれる先天的な色の好みは継承する。

## 第7章　毒システム

### 7.1 毒の種類

初期実装では4種類を用意する。

| 毒ID | 種類   | 特徴       |
| --- | ---- | -------- |
| A   | 即効毒  | 短時間にダメージ |
| B   | 継続毒  | 長時間にダメージ |
| C   | 高濃度毒 | 毒量に強く依存  |
| D   | 遅効毒  | 一定時間後に作用 |

これらは初期プリセットであり、毒の種類と効果の対応は設定データとして保持する。

毒の種類を追加しても戦闘AIや色認識の実装を変更しない構造とする。

### 7.2 毒データ

```
record ToxinTrait(
    int toxinTypeId,
    double potency,
    double dose,
    double duration,
    double delay,
    ToxinDelivery delivery
) {}
```

```
enum ToxinDelivery {
    INGESTION,
    ATTACK
}
```

### 7.3 毒ダメージ

\\[ D\_{\mathrm{toxin}} = P \times Q \times (1-R) \\]

- \\(P\\)：毒強度
- \\(Q\\)：基準毒量で正規化した実際の摂取・注入量
- \\(R\\)：対応抗体の防御率

計算された値は、その毒の効果時間全体で与える総ダメージとする。

継続毒は効果時間に応じて分割する。

例えば総ダメージ20、効果時間10 Tickなら、1 Tickあたり2ダメージを与える。

遅効毒は遅延時間が経過してからダメージを開始する。

### 7.4 毒の蓄積

同じ毒を複数回受けた場合は、独立した毒効果として保持する。

各毒効果は残りダメージ・残り時間を持つ。

複数の毒を受けた場合は、それぞれ独立して処理する。

### 7.5 毒の生成コスト

毒を生成する際にはエネルギーを消費する。

\\[ E\_{\mathrm{toxin}}= k_pP\Delta Q \\]

- \\(k_p\\)：生成コスト係数
- \\(P\\)：毒強度
- \\(\Delta Q\\)：生成した毒量

毒を使い切った場合は、時間をかけて再生成する。

植物についても、毒の維持・生成が成長資源を消費するものとする。

## 第8章　抗体システム

### 8.1 抗体データ

```
record AntibodyTrait(
    int toxinTypeId,
    double resistance,
    double capacity,
    double regeneration
) {}
```

抗体は対応する毒IDに対してのみ作用する。

例えば抗体Aは毒Aに作用するが、毒Bには作用しない。

### 8.2 抗体による防御

抗体の防御率を0〜1とする。

抗体Aの防御率が0.8なら、毒Aによる総ダメージを80%減少させる。

対応抗体を持たない場合は防御率0とする。

### 8.3 抗体容量

抗体には解毒可能量を設ける。

毒を受けると、対応抗体の容量を消費する。

容量が不足する場合は、解毒可能な毒量にのみ抗体を適用し、残りは防御率0として計算する。

容量は時間経過によって回復する。

### 8.4 抗体のコスト

抗体の維持にはエネルギーを消費する。

複数の抗体を持つ個体は、その分だけ維持コストが増える。

これにより、すべての毒に対応する抗体を持つ個体が無条件に有利になることを防ぐ。

## 第9章　攻撃・戦闘

### 9.1 基本ダメージ

\\[ D\_{\mathrm{attack}}= \max(1,Attack-Defense) \\]

攻撃力と防御力は成長度で補正した現在値を使用する。

### 9.2 攻撃条件

以下をすべて満たす場合に攻撃できる。

- 攻撃対象が存在する。
- 対象が生存している。
- 対象との距離が攻撃射程以内である。
- 攻撃クールダウンが0である。
- 攻撃に必要なエネルギーがある。

### 9.3 攻撃毒

攻撃側が攻撃毒を保有している場合、攻撃命中時に毒を注入する。

毒量を消費し、相手に毒効果を付与する。

### 9.4 戦闘中の再判断

動物は戦闘中も次の情報を評価する。

- 現在HP
- 相手へ与えたダメージ
- 相手から受けたダメージ
- 毒によるダメージ
- 空腹度
- 予測勝率
- 捕食による利益

毒を受けた場合でも、予測損害が小さく捕食利益が大きければ攻撃を続行する。

## 第10章　意思決定AI

### 10.1 行動状態

```
enum AnimalState {
    WANDER,
    CHASE,
    ATTACK,
    EAT,
    FLEE,
    REST,
    REPRODUCE
}
```

### 10.2 行動候補の評価

動物は各行動の効用を計算する。

追跡・攻撃の効用は次の要素から算出する。

\\[ U\_{\mathrm{attack}} = w_fHF+w_wW+w_aA -w_rR-w_cC \\]

- \\(H\\)：空腹度
- \\(F\\)：食料価値
- \\(W\\)：勝利期待値
- \\(A\\)：攻撃性
- \\(R\\)：予測危険
- \\(C\\)：戦闘・追跡コスト

各重みは行動遺伝子に基づいて設定する。

### 10.3 空腹による危険許容

\\[ T\_{\mathrm{risk}} = \operatorname{clamp} (T_0+kH,0,1) \\]

危険許容度が高いほど、危険による効用ペナルティを減少させる。

これにより、空腹時は危険な相手にも攻撃しやすくなる。

### 10.4 勝利経験

勝利経験は色の類似度を通じて、初めて見る対象にも適用する。

過去に勝った相手と似た色であれば、追跡・攻撃の効用が上昇する。

ただし、勝利経験があっても毒の危険度は独立して評価する。

### 10.5 行動選択

行動選択にはSoftmaxを使用する。

\\[ P(a)= \frac{e^{U(a)/\tau}} {\sum_b e^{U(b)/\tau}} \\]

\\(\tau\\) は行動のランダム性を決定する。

初期値は0.15とする。

数値計算時には、すべての効用から最大効用を引いてから指数関数を計算し、オーバーフローを防止する。

### 10.6 行動の継続

行動の頻繁な切り替えを防ぐため、以下を採用する。

- 行動判断間隔：5 Tick
- 追跡対象の継続ボーナス：0.1
- 通常行動の最低継続時間：3 Tick

ただし、致命的なダメージを受けた場合や対象が死亡した場合は即座に再判断する。

## 第11章　移動・索敵・逃走

### 11.1 索敵

動物を中心とする円形範囲を使用する。

\\[ Distance(a,b)\leq VisionRange \\]

初期実装では遮蔽物や視野角は考慮しない。

### 11.2 移動

\\[ P\_{t+1}=P_t+V\Delta t \\]

### 11.3 追跡

\\[ Direction= \frac{TargetPosition-SelfPosition} {\\|TargetPosition-SelfPosition\\|} \\]

### 11.4 逃走

\\[ Direction= \frac{SelfPosition-ThreatPosition} {\\|SelfPosition-ThreatPosition\\|} \\]

距離が0の場合は、乱数シードから決定的に生成した方向を使用する。

### 11.5 複数個体

各動物は独立して意思決定する。

複数の動物が同じ対象を攻撃することは許可するが、協調行動は行わない。

同時攻撃のダメージは収集してから一括適用する。

## 第12章　エネルギー・成長・死亡

### 12.1 エネルギー

\\[ E\_{t+1} = E_t+E\_{\mathrm{food}}-E\_{\mathrm{cost}} \\]

消費対象は以下とする。

- 基礎代謝
- 移動
- 攻撃
- 成長
- 毒生成
- 抗体維持
- 繁殖

### 12.2 空腹度

\\[ H= \operatorname{clamp} \left( 1-\frac{E}{E\_{\max}},0,1 \right) \\]

空腹度はエネルギー残量から算出する。

独立した状態変数として更新せず、必要時に計算することで整合性を保つ。

### 12.3 成長

\\[ Growth\_{t+1} = \min(1,Growth_t+GrowthRate\cdot f(E)) \\]

\\(f(E)\\) はエネルギー充足率に基づく0〜1の係数とする。

エネルギーが不足している場合は成長が遅くなる。

### 12.4 飢餓

エネルギーが0になった動物は、毎Tick最大HPの1%を失う。

HPが0以下になった場合は死亡する。

### 12.5 死体

死亡した生物は死体に変換する。

死体の栄養量は、生前の最大HPと残存エネルギーから算出する。

死体は時間経過で腐敗し、最終的に土地へ栄養を還元する。

## 第13章　繁殖・遺伝・突然変異

### 13.1 繁殖方式

初期実装は無性生殖とする。

親1体から子1体を生成する。

将来、有性生殖へ変更できるように遺伝子継承処理を独立させる。

### 13.2 繁殖条件

以下を満たす場合に繁殖可能とする。

- 成長度が1.0
- HPが最大HPの70%以上
- エネルギーが最大値の80%以上
- 繁殖クールダウンが0
- 周囲に子を生成できる空間がある

### 13.3 遺伝

子は親の遺伝子を複製して生成する。

各遺伝子について突然変異を判定する。

### 13.4 数値突然変異

\\[ G\_{\mathrm{child}} = \operatorname{clamp} (G\_{\mathrm{parent}}+\epsilon,G\_{\min},G\_{\max}) \\]

\\[ \epsilon\sim\mathcal{N}(0,\sigma_m^2) \\]

初期突然変異確率は各遺伝子座につき5%とする。

変異幅は原則として、その遺伝子の許容範囲の5%を標準偏差とする。

### 13.5 色の突然変異

RGB各成分に独立した数値変異を適用する。

変異後は0〜1へ制限する。

これにより、親と少し異なる体色の子が生まれる。

### 13.6 毒・抗体の種類変異

毒や抗体の種類そのものが変化する確率は、通常の数値変異より低く設定する。

初期値は0.1%とする。

変異後の種類は登録済みの毒IDから選択する。

初期実装では新しい毒の作用機構を自動生成しない。

## 第14章　1 Tickの処理順序

ここは実装時に重要な部分です。

同じTickで先に処理された個体が一方的に有利にならないよう、判断と結果の適用を分離します。

1. 土地の栄養更新
2. 植物の成長・発生・種子散布
3. 動物の代謝・成長・クールダウン更新
4. 継続毒のダメージ適用
5. 死亡判定と死体生成
6. 世界の状態をスナップショット化
7. 全動物の索敵・行動判断
8. 全動物の移動要求を収集・一括適用
9. 移動後の位置から攻撃・捕食要求を収集
10. 攻撃・毒注入を一括処理
11. 死亡判定・捕食可能資源の確定
12. 捕食・エネルギー獲得を処理
13. 戦闘・捕食・毒の経験を記憶へ反映
14. 繁殖・突然変異・子の生成
15. 死体の腐敗・土地への栄養還元
16. 統計記録・描画用データ更新

### 同時処理のルール

- 攻撃は、移動後の位置を基準に射程判定する。
- 同じTickに複数の攻撃が成立した場合、対象の死亡にかかわらず有効な攻撃要求を一括処理する。
- 死亡した動物は、そのTick内に新しい行動を開始できない。
- 同じ死体に複数の捕食要求がある場合、残存栄養量を超える摂取は許可しない。
- 毒による継続ダメージは、毒効果ごとの残存ダメージと残存時間に基づいて処理する。
- 子として生成された個体は、次のTickから行動する。

## 第17章　統計と検証

### 17.1 記録する統計

| 分類  | 指標             |
| --- | -------------- |
| 個体数 | 植物・草食動物・肉食動物   |
| 遺伝  | 世代数・突然変異数      |
| 色   | RGB分布・色別生存率    |
| 毒   | 毒種類別保有率・平均強度   |
| 抗体  | 抗体種類別保有率・平均防御率 |
| 戦闘  | 攻撃数・勝率・死亡数     |
| 学習  | 色別危険度・勝利期待値    |
| 捕食  | 捕食成功率・毒による死亡率  |
| 繁殖  | 繁殖回数・子孫数       |

### 17.2 必須テスト

最低限、以下のテストを実施する。

1. 同じ色の記憶がある場合、その評価が予測へ強く反映されること。
2. 類似色への学習効果が色距離に応じて減少すること。
3. 空腹度が上昇すると、他条件が同じ場合に危険な相手への攻撃傾向が上昇すること。
4. 弱い毒を受けても、捕食利益が大きければ攻撃を続行できること。
5. 対応抗体のみが毒ダメージを減少させること。
6. 勝利経験が似た色の対象への追跡意欲を高めること。
7. 突然変異後の遺伝子が許容範囲内に収まること。
8. 子が親の記憶を直接継承しないこと。
9. 複数個体の同時攻撃で、処理順序による不公平が発生しないこと。
10. 同じ初期条件と乱数シードで同じ結果を再現できること。

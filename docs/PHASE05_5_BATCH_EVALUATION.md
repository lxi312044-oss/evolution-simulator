# Phase 05.5 — 複数シード・長期実行・統計評価

## 実装範囲
RustネイティブのCLIバッチ評価 (`sim-core/examples/batch_evaluation.rs`) を追加。ブラウザUIには未統合。

## 実行例（プロジェクトルートで実行）
```powershell
cargo run --release -p sim-core --example batch_evaluation -- config/phase055-longrun.json 50000 100 12345,12346,12347,12348,12349 results/phase055
```
引数は順に設定JSON、目標Tick、CSVサンプリング間隔、カンマ区切りシード、出力先ディレクトリ。

## 出力
- `timeseries.csv`: シードごとのTick、植物・草食動物数、出生・死亡累積、土壌・有機物N
- `per_seed.csv`: 最終個体数、観測上の初回絶滅Tick、観測最小/最大、サンプル平均、エラー
- `summary.csv`: 正常完走シード数、共存率、最終個体数の平均・中央値・最小・最大

## 注意
- 絶滅Tickはサンプル間隔単位の**初回観測Tick**であり、正確な死亡Tickではない。
- エラーシードは正常完走率・生存率の分母に入れず、failed_seedsとして別集計する。成功率は完走シードに対する割合。
- 複数シードを並列化せず順次実行するため、処理時間はシード数に比例する。
- 長期実行で `ConservationError` が発生した場合は `per_seed.csv` に記録する。エネルギー収支検査の許容値は変更しない。
- 設定はブラウザの表示値ではなく `config/phase055-longrun.json` を使用する。ブラウザで検証した設定と一致するか必ず確認する。
- バッチ評価は生態系の安定性を証明するものではない。複数シードで生存率、極小個体数、再現性を評価する。

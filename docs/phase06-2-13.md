# Phase 06.2.13 — 肉食動物の持続的探索・獲物記憶・壁反射

## 原因と修正
視界内に獲物がいないとき、旧実装は毎Tick独立に方向を抽選するランダムウォークだった。これにより長距離移動しにくい。新方式は進行方向を指定Tick維持し、獲物を見失っても直前の方向へ指定Tick進み、壁では方向を反射する。獲物が視界内にいる場合は常に追跡を優先する。満腹時は停止し、探索メモリを減らさない。

## 設定
- `persistent_search_enabled` 標準OFF。ONで新しい探索行動。
- `search_heading_ticks` 方向維持期間。デフォルト90。
- `lost_prey_memory_ticks` 見失った後の追跡継続。デフォルト45。

## 比較条件（各10シード、50,000 Tick）
- `control`: 従来ランダム探索
- `persistent`: 90 Tick直進・45 Tick記憶
- `long-memory`: 90 Tick直進・120 Tick記憶
- `long-stride`: 180 Tick直進・45 Tick記憶

比較設定はフェーズ06.2.12のcontrolから派生し、空腹判定の差を入れず探索だけを比較する。

## 実行
```powershell
cargo test --workspace
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_phase06213.ps1 -Ticks 1000 -SeedCount 2
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_phase06213.ps1
```

出力は `results/phase06213/`。追加CSV列は `persistent_search_ticks`, `remembered_prey_ticks`, `search_heading_changes`, `search_wall_turns`。移動距離・狩猟成功・絶滅Tick・N/E誤差を比較する。新方式のOFF時は旧RNG消費を保持する。

# フェーズ05.2 満腹度・捕食制御

## 実装

- `satiety_enabled` をON/OFFでき、OFF時は従来の捕食と資源連動繁殖を維持します。
- 胃内容物は独立した栄養N口座です。植物の体N → 胃N（吸収分）、植物の体N → 有機物N（排泄分）、胃N → 草食動物の貯蔵N（消化）として移動し、Nを生成しません。
- ON時は胃容量の80%で捕食探索を停止し、消化によって40%以下になると再開します。停止中も従来の探索移動・代謝は続きます。
- 胃が満杯になる摂食は上限で制限し、死亡時は胃Nを有機物に戻します。子の胃は空で生成します。
- **注意:** 今回の段階では摂食に伴う化学エネルギーEの移転は従来どおり即時処理であり、胃でのエネルギー消化遅延は未実装です。

## UI・CSV

- 満腹度ON/OFF、胃容量N、捕食停止率、捕食再開率、消化速度N/Tickを変更できます。変更後に「設定を適用してリセット」を押してください。
- CSV: `herbivore_stomach_n`, `herbivore_satiety_mean`, `herbivore_satiety_min`, `herbivore_satiety_max`（現在値）、`herbivore_satiety_blocked_ticks`（累積）、`herbivore_digested_n`（累積）。
- 診断値は100 Tickごとに記録されます。

## 比較方法

循環改善プリセットを選択し、資源連動繁殖のON/OFFを固定したまま、満腹度だけOFF/ONでそれぞれ7,000 Tickを実行しCSVを比較します。種子・植物数、捕食数、出生数、絶滅時期、栄養保存誤差、エネルギー収支を確認します。

# フェーズ06.2.20 — 周期停止の診断

06.2.19 Web検証で、植物回復後の草食動物繁殖不振と、草食動物増殖期の肉食動物繁殖不振を確認。今回は行動パラメータを変更せず、原因を観測します。

## 検証条件

- control / plant-150 / herbivore-120 / combined
- 5 seeds × 50,000 ticks、100 Tick間隔
- 全条件で肉食動物の基礎代謝は06.2.19と同じ0.018 E/Tick
- 強制的な絶滅防止は行いません。

## 新しいCSV項目

- phase20_feeding_*: 探索・接近・摂食成功／失敗の分類（累計個体Tick）
- phase20_repro_*: **先に該当した1条件だけ**を記録する順序付き繁殖阻害診断（累計個体Tick）
- phase20_herbivore_death_*: 死亡時の近傍植物数、身体E、胃内Nの合計とサンプル数

**重要:** 順序付き診断は各条件の真の同時発生頻度を表しません。最初に該当した阻害要因のみを記録します。死亡時の近傍植物数は、死亡時の視野内の数であり、可食性や摂食成功を保証しません。HP死亡の原因を厳密に餓死／捕食死へ分解する実装はまだありません。

## 実行

```powershell
cargo test --workspace
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_phase06220.ps1 -Ticks 1000 -SeedCount 1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_phase06220.ps1
```

出力: results/phase06220/summary.csv と各seed CSV。Webの動作は06.2.19のままです。

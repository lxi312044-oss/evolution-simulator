### 結果（16 seedの中央値）
**Q1 踏みとどまる割合**：肉食の探知範囲内にいた草食のうち、踏みとどまっていたのは **約10%**（seedごとに5.6〜13.7%）。ほとんどは逃げる。

**Q2・Q3 遺伝子の変化と選択**
| 遺伝子 | pred：開始 → 8,000 Tick → 最後 | nopred：開始 → 8,000 → 最後 | 生涯出産数の比（上位1/4 ÷ 下位1/4）pred | 同 nopred |
|---|---|---|---:|---:|
| 体力（体の大きさ） | 59.5 → 57.7 → 57.4 | 59.5 → 56.7 → 57.6 | **0.87** | 0.95 |
| 攻撃性 | 0.44 → 0.38 → 0.40 | 0.44 → 0.44 → 0.48 | **0.91** | 1.02 |
| 恐れやすさ | 0.65 → 0.66 → 0.67 | 0.65 → 0.64 → 0.64 | 1.07 | 0.98 |
| 速さ | 2.52 → 3.84 → 3.84 | 2.52 → 1.95 → 2.18 | **1.28** | 0.92 |

- 捕食があると、**攻撃性は不利**（減る）、恐れやすさはやや有利、**速さが最も強く選ばれる**。
- **体が大きいことは、捕食の有無にかかわらずやや不利**（捕食ありで0.87、なしで0.95）。今のモデルでは、大きいと維持費と移動費が増えるが、得になる点が少ない（噛まれるダメージは固定5で、体力が多いと死ぬまでの噛みつき回数が増えるだけ）。
- 踏みとどまっても、受けるダメージが半分になるだけで肉食は傷つかず、学習もしない。そのため「戦う」より「逃げる」が選ばれている。

### 限界
死因（捕食か飢えか）は個体ごとに区別していない。踏みとどまる割合は100 Tickごとの瞬間の値。遺伝子同士の相関は分けていない。保存則の監査はしていない。

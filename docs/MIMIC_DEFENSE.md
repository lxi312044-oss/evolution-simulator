## 段階1：今の強さ・攻撃性・踏みとどまる行動の計測（計測のみ、2026-11-18）

計画：https://github.com/lxi312044-oss/evolution-simulator/issues/54#issuecomment-6976267702

- 条件：20×20、段階4の設定に Issue 11 第3回の w_E。seed 90001〜90016、20,000 Tick、100 Tickごと。pred（肉食あり）、nopred（肉食を無効化）。
- 集計：`tools/analyze_defense_baseline.py`。結果ファイル（リポジトリ外）32ファイル、全体のハッシュ `749479f43fc90c585c234057603885b9ed2a35024e843050551d57a58afe693e`。
- 確認：pred の頭数の推移は Issue 11 の w_E と同じ（seed 90001 で20,000 Tickの草食362頭など、これまでの結果と一致）。

### 結果（16 seedの中央値）
**Q1 踏みとどまる割合**：肉食の探知範囲内にいた草食のうち、踏みとどまっていたのは **約10%**（seedごとに5.6〜13.7%）。ほとんどは逃げる。

**Q2・Q3 遺伝子の変化と選択**
| 遺伝子 | pred：開始 → 8,000 Tick → 最後 | nopred：開始 → 8,000 → 最後 | 生涯出産数の比（上位1/4 ÷ 下位1/4）pred | 同 nopred |
|---|---|---|---:|---:|
| 体力（体の大きさ） | 59.5 → 57.7 → 57.4 | 59.5 → 56.7 → 57.6 | **0.87** | 0.95 |
| 攻撃性 | 0.44 → 0.38 → 0.40 | 0.44 → 0.44 → 0.48 | **0.91** | 1.02 |
| 恐れやすさ | 0.65 → 0.66 → 0.67 | 0.65 → 0.64 → 0.64 | 1.07 | 0.98 |
| 速さ | 2.52 → 3.84 → 3.84 | 2.52 → 1.95 → 2.18 | **1.28** | 0.92 |

- 捕食があると、**攻撃性は不利**（減る）、恐れやすさはやや有利、**速さが最も強く選ばれる**。
- **体が大きいことは、捕食の有無にかかわらずやや不利**（捕食ありで0.87、なしで0.95）。今のモデルでは、大きいと維持費と移動費が増えるが、得になる点が少ない（噛まれるダメージは固定5で、体力が多いと死ぬまでの噛みつき回数が増えるだけ）。
- 踏みとどまっても、受けるダメージが半分になるだけで肉食は傷つかず、学習もしない。そのため「戦う」より「逃げる」が選ばれている。

### 限界
死因（捕食か飢えか）は個体ごとに区別していない。踏みとどまる割合は100 Tickごとの瞬間の値。遺伝子同士の相関は分けていない。保存則の監査はしていない。

## 段階2：反撃と学習の実装（2026-11-18）

計画：https://github.com/lxi312044-oss/evolution-simulator/issues/54#issuecomment-6976559257 、変更：https://github.com/lxi312044-oss/evolution-simulator/issues/54#issuecomment-6976705347

- 設定（opt-in、既定値は保存JSONに出ない）：草食の `counterattack_energy`（既定0）、`counterattack_learning_enabled`（既定 true）。
- **反撃**：噛まれた草食は、姿勢に関係なく、肉食の予備エネルギーから `counterattack_energy` × 攻撃性 ×（体力の遺伝子 ÷ 60）を減らす（残高まで、熱として散逸）。
  - 当初は「踏みとどまっている草食だけ」の予定だったが、噛まれる距離ではほぼ全員が逃げるため反撃が起きず（攻撃性 − 恐れやすさ ＞ 約0.21 が必要で、該当は0.5%）、ユーザーの判断で変更した（commit 28a61ed）。
- **学習**：肉食の色の学習が有効で `counterattack_learning_enabled` なら、反撃を受けた肉食はその色の記憶に 反撃量 ÷ 60 の害を加える（毒と同じ記憶、上限0.1）。
- 計数：`World::defense`（反撃の回数・量・学習の回数）。診断専用で、状態監査には出さない。
- commit 308da94、28a61ed。テスト `tests/counterattack.rs`（5件）。

- 肉食の色の記憶は弱まらず、似た色（色の距離0.25未満）にも広がる。初期の草食の色は互いに近いものが多く、避けすぎにつながったとみられる（未確認）。

- 反撃しても、噛まれた草食はそのまま噛まれ続けて倒されうる。反撃の得（肉食がその色を避ける）は、強い個体自身よりも、あとで同じ色の個体が受ける。強い個体は体の維持費を払い、最初の遭遇で倒されることもある。そのため、強さが直接の得にならない。

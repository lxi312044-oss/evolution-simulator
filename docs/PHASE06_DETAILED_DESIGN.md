# フェーズ06.0 詳細設計書 — 肉食動物・求愛／有性生殖・ドット絵

- 状態: **設計案（未実装）**
- 基準: フェーズ05.5.1 ソース構成、およびフェーズ05.5.2 の30シード×100,000 Tick検証
- 既知課題: 草食動物の絶滅 5/30 シード。肉食動物追加による悪化を監視する。

## 1. 目的・範囲

植物→草食動物→肉食動物の食物連鎖を導入する。草食動物・肉食動物をドット絵で視覚的に区別し、既存の無性生殖に加えて「同種個体への繁殖シグナル→相互接近→接触→有性生殖」を選択式で追加する。既存のN保存・E収支・seed決定性・バッチ評価を維持する。

実装順序: 06.1 表示 → 06.2 肉食動物（既存方式の繁殖）→ 06.3 求愛・有性生殖 → 06.4 複数シード検証。各段階で機能フラグOFF時の後方互換を検証する。

## 2. 既存構造との接続点

確認済みソース: `crates/sim-core/src/config.rs` の `SimulationConfig` は `plants`, `herbivores` を持ち、`InitialPopulation` は `carnivores` を既に持つが、肉食動物設定は未定義。`#[serde(default, deny_unknown_fields)]` および `version == "1.2"` の検証がある。`crates/sim-core/src/world/mod.rs` は `state`, `tick`, `herbivore_tick`, `diagnostics` に分割されている。

設計上は `CarnivoreSettings` と `MatingSettings` を追加し、旧JSONにフィールドがなくても既定値で読み込めるようにする。バージョン移行方法は実装時に明示し、既存設定を読み込めなくしない。`initial_population.carnivores = 0` と `carnivores.enabled = false` を初期値とし、既存条件の再現性を守る。

## 3. 個体モデル

### 3.1 共通

`AnimalId`（再利用しない一意ID）、種別、位置、方向、年齢、HP、エネルギー、体内N・予備N・胃N、遺伝子、行動状態、繁殖クールダウン、繁殖相手ID、求愛タイムアウト、乱数処理に必要な情報を保持。個体削除時は参照先の相手IDを無効化する。個体配列の添字をIDとして扱わない。

### 3.2 肉食動物

初期遺伝子候補: 最高HP、移動速度、視野、狩猟成功に関わる能力。狩猟・代謝・寿命・飢餓・繁殖・死亡を持つ。初期値は**暫定値**であり、既存のN/E台帳との整合を確認してから確定する。草食動物の個体数が少ないため初期肉食動物数は低く設定し、0体条件を対照群とする。

## 4. 行動優先順位と状態遷移

1. 死亡／状態異常処理
2. 草食動物の危険回避（捕食者を認識した場合）
3. 飢餓時の採食／狩猟
4. 既に成立した求愛ペアとの合流
5. 求愛シグナルの送受信・相手選択
6. 通常探索／休息

状態: `Explore`, `ForageOrHunt`, `Flee`, `CourtshipSignal`, `ApproachMate`, `Mate`, `Rest`。状態切替は原則として各Tickに1回、同Tickに二重繁殖しない。危険・飢餓・相手消失・時間切れで求愛を中断する。相手のID、種別、生存、繁殖可能性を接触時に再検証する。

## 5. 捕食アルゴリズム

1. 肉食動物は視野内の生存草食動物からターゲットを選ぶ（距離を優先、同距離は安定したID順）。
2. 移動・追跡は既存移動コストと整合させる。草食動物は認識距離内の捕食者から逃走する。
3. 捕食距離内で確率判定を行う。成功時は獲物のNを捕食者の胃／予備Nとデトリタスへ**過不足なく分配**する。エネルギーは獲物から捕食者へ移す分と熱放出へ移す分を明示する。
4. 失敗時にも追跡・攻撃の消費エネルギーを記録する。死亡個体を同Tickに複数回捕食しない。
5. 捕食停止条件（草食動物の保護）は初期設計では任意設定。人工的な保護あり／なしを別実験とし、標準結果と混同しない。

## 6. 有性生殖・求愛シグナル

### 6.1 切替

種ごとに `reproduction_mode = asexual | sexual`。既定は `asexual`（従来動作）。有性生殖は同種間のみ。性別モデルは最初の実装では導入せず、条件を満たす2個体の対称的ペアリングとする（将来拡張可能）。

### 6.2 求愛

- 既存の年齢・HP・E・N・満腹・クールダウン条件を満たすと、求愛可能となる。
- 半径 `signal_radius` 内の同種で繁殖可能な相手にシグナルを送る。シグナルは資源を生成しない。必要なら求愛コストをE→熱へ記帳する。
- 両者が互いを選び、ペアを確定する。相手選択は距離優先、同距離はID順で決定性を確保する。1個体が同時に複数ペアに入らない。
- 両者が `contact_radius` 以内へ移動。`timeout_ticks` を超える、捕食者に追われる、飢餓になる、相手が死亡する場合は解消する。
- 接触時に条件を再検査し、両親の資源から子の初期資源と繁殖コストを差し引く。資源不足なら生成しない。
- 子の遺伝子は各形質について両親から選択または平均化（方式は設定で固定）し、その後に突然変異。親のクールダウンを更新。

### 6.3 暫定パラメータ

`signal_radius`, `contact_radius`, `timeout_ticks`, `courtship_energy_per_tick`, `reproduction_work_energy`, `mutation_probability`, `mutation_scale`。距離・時間・コストの数値は初期実装で試験調整する。特に個体数の少ない環境では有性生殖の相手不足（アリー効果）を計測する。

## 7. 資源台帳の不変条件

- **N**: `soil + detritus + plants + herbivores(body+reserve+stomach) + carnivores(body+reserve+stomach)` が初期総Nと一致する（既存の保存則許容誤差を維持）。
- **E**: `生物と環境に残るE + heat_out - sunlight_in = 初期E`（既存台帳定義に合わせる）。捕食・繁殖・死亡の移転でEを生成・消滅させない。
- フェーズ05.5.1の補償付き加算を継続使用。診断のための誤差閾値を安易に緩めない。
- 生物死亡時の胃N、親から子への資源移転、狩猟成功時の部分摂取・残骸が必須テスト対象。

## 8. 描画・ドット絵

- 草食動物は**ウサギ型**（茶系・長耳）、肉食動物は**キツネ型**（橙系・尖耳）。色だけに頼らずシルエットも異ならせる。
- 16×16または32×32の透過PNGスプライトを想定。Canvas上で近傍補間OFF（`imageSmoothingEnabled = false`）、方向反転、サイズ調整。
- 求愛時はハート／波紋、捕食追跡時は視認できる小さなマークを任意表示。個体数が多い場合は描画負荷対策として画面外描画を省略。
- 画像読み込み失敗時は既存の図形描画にフォールバック。シミュレーションの乱数・Tick進行は描画に依存しない。
- アセット制作とコードへの組込みはフェーズ06.1で行う。本設計書自体には画像を含めない。

## 9. UI・設定・CSV

- UI: 肉食動物ON/OFF、初期個体数、狩猟パラメータ、草食／肉食それぞれの繁殖方式、求愛半径・接触距離・タイムアウト、スプライト表示ON/OFF。
- CSV: `carnivore_count`, `carnivore_births`, `carnivore_deaths`, `predation_attempts`, `predation_successes`, `herbivore_predation_deaths`, `courtship_signals`, `pairs_formed`, `pair_timeouts`, `mating_successes`, `mating_failures_resource`, `energy_delta`, `nutrient_delta`。累積値と区間差分は明示的に区別する。
- バッチ評価: 既存の `per_seed.csv`, `timeseries.csv`, `summary.csv` を拡張。三種共存率、草食動物・肉食動物の初回絶滅Tick、最終個体数、後半傾向、保存則エラー、求愛成立率を集計する。
- CSVには使用設定、シード、バージョン、繁殖方式を識別できる情報を残す。

## 12. 未決定事項

- 捕食成功率と肉食動物の初期数・代謝値（基準データで校正）。
- 両親の遺伝子組換え方式（ランダム選択／平均）。

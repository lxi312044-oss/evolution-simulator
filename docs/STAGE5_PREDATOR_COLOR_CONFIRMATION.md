# 段階5の確認結果 — 肉食の色学習と初期草食RGB

[Issue #39](https://github.com/lxi312044-oss/evolution-simulator/issues/39) の事前指定どおり、[段階4の候補設定](STAGE4_FIXED_EXPERIMENT.md)（閾値0.05・係数0.50）で肉食の色学習だけをON/OFFにした。生態ソースと設定は段階4固定版から変更していない。実行版は [2e917a3](https://github.com/lxi312044-oss/evolution-simulator/commit/2e917a332af2289cf078b3f1710cdb0b9c3ebdde)。

## 主要判定

seed 1574032001～1574032128の128対・256条件を各6,000 Tickまで完走。主要指標は初期草食を起点とする第1世代以降の累積出生数。全初期個体10,240対を対象とし、子孫ゼロと起点の途中除去を含む。ON−OFFの差をseedごとに初期可視RGBへ同時回帰し、seedを等重みで集計。

| 初期色成分 | 傾きの平均 | Bonferroni同時95%区間 | seed間SD |
| --- | ---: | --- | ---: |
| R | +0.01750 | [−0.06460, +0.09960] | 0.38286 |
| G | +0.00053 | [−0.08426, +0.08532] | 0.39540 |
| B | −0.04422 | [−0.13479, +0.04636] | 0.42237 |

単位は正規化RGBの1成分0.1当たりの出生／起点。全区間が事前指定の±0.25に収まり、**指定した線形尺度で意味のある関係の変化は不支持**。局所的・非線形の色依存は主要判定の範囲外。初期色は操作していない。試験完了と、適応進化・擬態の成立は別判定とする。

## 補助解析

初期属性を調整した128対の記述的な傾きはR +0.03124 [−0.05449, +0.11696]、G +0.00654 [−0.08382, +0.09690]、B −0.03560 [−0.12789, +0.05669]。肉食学習ON/OFFの累積出生平均は2.68193／2.61055、子孫ゼロは4,326／4,307（各10,240起点）。ONで記憶に対応する攻撃可能候補は35,713件、実攻撃31,181件・色拒否2,531件・その他2,001件。候補機会単位の集計で、主要評価の独立反復や学習の媒介効果として扱わない。

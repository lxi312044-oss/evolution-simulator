# フェーズ05.3：満腹度と繁殖の連動

## 仕様
- 満腹連動繁殖を独立して ON/OFF 可能（初期値 OFF）。
- ON では満腹度システムも ON が必要（UI で検証）。
- 胃N/胃容量が閾値（初期50%）以上で連続100 Tick経過した個体だけ繁殖候補になる。
- 1 Tickでも閾値未満なら継続カウンターを0に戻す。
- 既存の年齢、HP、E、N、クールダウン、資源連動繁殖条件は維持。
- 親の胃Nは子に直接移さず、親の体N・貯蔵N・Eから子へ移転。
- 胃Nは既存N口座、満腹継続Tickは非資源の状態値。保存則は変更しない。
- `herbivore_reproduction_satiety_blocked` は繁殖候補の満腹条件未達回数（累積）。

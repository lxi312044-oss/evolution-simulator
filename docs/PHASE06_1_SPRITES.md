# フェーズ06.1 — 動物ドット絵とCanvas描画

状態: 実装済み（ブラウザ動作の実機検証待ち）

## 実装
- `web/src/sprites.ts` に草食動物（ウサギ型）と肉食動物（キツネ型）の16×16ピクセルスプライトを定義。
- 外部画像への依存なし。初回だけオフスクリーンCanvasへ描画してキャッシュし、描画時に `imageSmoothingEnabled=false` で拡大する。
- `web/src/main.ts` の草食動物描画を円からウサギ型ドット絵へ変更。HP30%未満は赤い小さなマークで表示。
- 肉食動物は凡例のプレビューのみ。**肉食動物の個体・捕食・繁殖・WASMスナップショットはフェーズ06.2で実装予定**。存在しない肉食動物をシミュレーション画面に表示しない。
- Rustシミュレーション・N/E台帳・乱数処理・CSV形式は変更していない。

## 動作確認
1. プロジェクトルートで `cargo test --workspace`。
2. `wasm-pack build crates/sim-wasm --target web --out-dir ../../web/src/pkg`。
3. `cd web && npm install && npm run dev`。
4. 草食動物がウサギ型のドット絵として表示され、動くことを確認する。
5. 凡例にキツネ型のプレビューがあり、実際のマップにはまだ肉食動物がいないことを確認する。
6. CSVと保存則テストが以前と同じ条件で実行できることを確認する。

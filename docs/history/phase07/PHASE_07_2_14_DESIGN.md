# Phase 07.2.14 — 急減後の個体群回復・無出生区間の診断

## 仮説と分析範囲

Phase 07.2.13で、B/Fとも3,200〜4,000 Tick付近で最初の大きな急減と出生数ゼロが観測された。今回、既存40ランの100 Tick区間データから、3,000〜6,000 Tickの無出生区間と6,000〜10,000 Tickの個体群変化を比較する。

### 固定した操作的定義
- 無出生区間: 開始時に草食が存在し、出生0である連続100 Tick区間。観測対象は3,000〜6,000 Tick。
- 回復: 6,000→10,000 Tickの草食個体数が増加した場合。開始個体数ゼロの場合は復活と別記。
- 出生・死亡・曝露・捕食試行率: 各区間の平均草食個体数 × Tick幅を分母とする1000個体Tickあたりの率。
- 1000 Tick固定窓を併記し、重複移動窓による二重計数を避ける。

## 解析上の限界
- 出生数ゼロは、繁殖可能個体ゼロ、繁殖条件不成立、確率的な無出生を区別できない。
- 個体数変化は出生と死亡の差であり、死亡原因を特定しない。
- 捕食試行は捕食死ではなく、毒曝露は毒死ではない。
- 回復の有無による事後層別から因果効果は結論できない。
- 自然選択の検証に戻るため、原因特定を目的化しすぎない。

## 次の判断
- 既存集計で出生停止理由が識別できない場合のみ、Rust側に観測専用の繁殖適格個体数、繁殖試行、繁殖失敗理由、年齢構成、死因別カウンタを追加する。
- 進化・繁殖パラメータを結果に合わせて変更しない。

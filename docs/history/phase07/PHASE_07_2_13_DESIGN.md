# Phase 07.2.13 — 個体群急減・絶滅と毒曝露・捕食圧の時系列分析

## 目的
Phase 07.2.12.1で整合性確認済みの40ランの観測CSVを再利用し、時系列で急減と毒曝露・捕食試行の時間的順序を調査する。生態・遺伝・毒ロジックは変更しない。

## 観測上の定義
- 急減: 草食個体数が1,000 Tickの観測窓で30%以上減少（開始時の草食数 > 0）。最初に該当する窓を記録。
- 個体数ゼロ: 最初にゼロを観測したTickと、最終Tickでゼロかを別々に記録。ゼロは不可逆な絶滅と同義ではない。
- 急減前の窓: 急減窓の開始Tickより前の1,000 Tick。急減窓と重複させない。
- 観測間隔は原則100 Tick。欠測窓の補間は行わない。
- 毒曝露と捕食試行の1000草食個体Tickあたりの概算率を算出する。母数は両端個体数の平均による近似であり、正確な個体時間ではない。

## 解釈
- 事後的に急減を選ぶと選択バイアスがあり、因果効果の推定ではない。
- 捕食試行や攻撃後HPゼロは捕食死の直接観測ではない。
- 先行関係は因果を確定しない。主要評価のF−B耐性生存率差とは区別する。
- 条件ごとの急減数、時刻、直前曝露・捕食試行を記述的に比較する。

# Phase 07.2.16 — 繁殖停止の直接原因と資源不足の時間的検証

## 目的
2,500–6,500 Tickの100 Tick時系列において、繁殖条件成立率、出生、HP死の前後関係を記述する。生態・遺伝・毒のルールは変更しない。

## 入力
Phase07.2.15の `*.reproduction.csv` 40ラン。Phase07.2.13の `interval_rates.csv` は補助的な捕食・毒曝露データとして使用可能。ただし別実験であるため個体単位で結合せず、同一seed/tickの参考指標に限定する。

## 判定
- 40ラン、20ペア、50,000 Tickの完全性を確認する。
- 100 Tickの出生・条件成立率を算出し、1区間先行した値と次区間出生を対応させる。
- 資源量（植物・土壌栄養）の時系列がない場合、資源不足の直接証明は「未判定」とする。
- 観測指標と実際の繁殖処理の差異を明記する。

## 出力
`results/phase07216/analysis/` に5 CSV/JSON/Markdownを生成。元CSVはローカルに保管し共有不要。

## 課題
- 継続観察: 無出生期間の原因（エネルギー不足と満腹不足の関連は観測、直接原因は未特定）
- 未着手: 同一ランの植物・土壌栄養の100 Tick時系列を突合する仕組み
- 継続観察: 自然選択の検出力と遺伝子頻度の変化

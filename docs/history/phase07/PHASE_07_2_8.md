# Phase 07.2.8 — 選択圧の検出力と交絡要因の検証

## 目的
Phase 07.2.7 のコホート集計（30実験・247コホート）から、シード間の不確実性、少数コホートへの依存、環境条件間の差、曝露・維持コストとの観測上の関連を評価する。生態・進化ロジックは変更しない。

## 範囲
- `tools/analyze_phase0728.py` による標準ライブラリのみの再解析。
- 元の約10GBの個体イベントCSVは不要。`results/phase0727/analysis/cohort_comparisons.csv` を入力。
- `results/phase0728/analysis/` にシード集計、条件別bootstrap区間、対応シード条件比較、交絡監査、品質チェック、レポートを出力。

## 判定基準
- 30実験の入力を受理し、数値・差分・重複の整合性を検査できる。
- シードを独立単位として不確実性を表示できる。
- 曝露の内生性、選択バイアス、5シードの統計的不安定性を明示する。
- 自然選択の因果成立を推定・断定しない。

## 検証結果
共有された Phase 07.2.7 の `cohort_comparisons.csv` で実行し、30実験、247コホート、追加品質警告0を確認。Python構文・解析実行・出力生成を検証済み。Rustテストはこのフェーズで未実施（Rustコード変更なし）。

## 制約・継続課題
- 集計表から個体レベルの因果モデルや正式な検出力解析はできない。
- 5シードbootstrap区間は探索的で不安定。符号反転p値は多重比較未補正。
- 毒曝露は摂食・生存に依存するため、曝露と生存の相関を因果効果としない。
- 旧検証スクリプトのアーカイブ後の動作保証は引き続き未完了。

## 次フェーズへの引継ぎ
事前登録する評価指標、実験単位、必要効果量、追加シードの予備設計を検討。進化パラメータを結果に合わせて変更しない。

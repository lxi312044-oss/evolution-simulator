# Phase 07.2.10 — 追加予備実験の事前設計

## 目的
Phase 07.2.9の5独立シードでは分散推定が不安定なため、追加15独立シードを用い、主要比較候補F−Bのシード間分散を再推定する。自然選択の因果成立の確証検定ではない。

## 事前固定
- ユーザー承認済み最小検出効果量: **生存率差2パーセントポイント（0.02）**。
- 主要指標: 出生後1000 Tickの高耐性−低耐性生存率差。
- 副次指標: 同期間の高耐性−低耐性繁殖成功数差。
- 主要比較候補（正式承認前）: F強毒・維持コストONとB毒OFF・維持コストONの**高耐性−低耐性差の差**。F−Bが正なら、強毒条件下での耐性優位が毒OFFより大きいことを意味する。
- 追加シード: 12350〜12364の15シード。既存12345〜12349と重複しない。
- 対象条件: BとF。15×2=30追加ラン、各50,000 Tick。既存の全6条件×5シードは保存し、再実行しない。
- 生態・遺伝・毒パラメータ: Phase 07.2.7と同一。変更しない。
- コホート幅: 5000 Tick。観測期間: 1000 Tick。低耐性<0.49、高耐性>0.51。中間帯除外。
- 各シードの比較可能なコホートを少人数群サイズで加重。独立反復はシード。
- 比較可能コホートがないシードは欠損とし、ゼロ差を代入しない。欠損件数と理由を報告。
- 予備段階での有意性による途中停止・シード追加は禁止。追加実験の計画を変更する場合は新しいフェーズで明記。

## 成功条件
1. 追加B/Fそれぞれ15シードのイベントCSV生成。
2. 追加結果から出生コホート別の生存・繁殖差を再集計。
3. 既存5シードと合わせて最大20ペアシードの分散、平均、欠損数を報告。
4. 2ポイントを検出するための必要シード数を探索的に再概算。
5. 自然選択の因果判定、世代間頻度の成立判定はこのフェーズでは保留。

## 実行手順（PowerShell 5.1対応）
短時間のスモークテストは**本番シードと別のseed**を使用するか、既存結果を上書きしないようにする。例:

```powershell
.\tools\run_phase07210.ps1 -Ticks 1100 -StartSeed 22345 -SeedCount 1 -DryRun
```

本番:

```powershell
.\tools\run_phase07210.ps1 -Ticks 50000 -StartSeed 12350 -SeedCount 15
python .\tools\analyze_phase0727.py --root .\results\phase07210\runs --out .\results\phase07210\analysis
python .\tools\analyze_phase07210.py --pilot .\results\phase0728\analysis\seed_summary.csv --new .\results\phase07210\analysis\cohort_comparisons.csv --out .\results\phase07210\analysis\design
```

共有は `results/phase07210/analysis/` の軽量CSV・JSON・REPORT.mdのみ。約10GB規模の生イベントCSVはローカル保存。

## 判定と注意
- 必要シード数は正規近似による概算であり、統計的検出力の保証ではない。
- 主要比較F−Bは提案に基づく暫定採用。確証的な次段階の前にユーザーの正式確認を取る。
- 出生コホート内の高/低耐性は無作為割付でなく、環境・遺伝・行動による交絡が残る。
- Phase 07.2.7観測で死亡Tick内イベントを欠落する可能性がある問題は継続観察。

# Phase 07.2.12 — 初期遺伝子分布・個体群動態・捕食圧の観測強化

## 目的
Phase 07.2.10 の20ペアシードで観測された F−B 生存率差のばらつきについて、初期耐性分布・個体群規模・捕食機会の関連を記述的に調べる。

## 範囲
- Rustの生態・遺伝・毒パラメータは変更しない。
- 既存の巨大な個体イベントCSVを出力せず、100 Tick間隔の軽量な観測CSVを出力する。
- B/F条件の既存20シードと同一設定・同一コードで再実行する。過去の元イベントCSVは不要。
- シードごとに初期耐性分布と個体数・出生・死亡・捕食試行・捕食で正のエネルギーを得た攻撃・毒曝露を出力する。

## 重要な制約
初期個体の耐性値は `state.rs` で `config.toxin.initial_resistance` に固定されており、現行の初期集団には耐性のシード間分散がない可能性が高い。これは観測結果を見て確認する。
`prey_hp_zero_after_attack` は捕食による死亡数と同一とは限らない。`hunt_positive_energy` も捕食成功の厳密な定義ではない。実験条件や乱数消費順序が過去版と変わっていないことの検証が必要。

## 完了基準
1. Rustビルドと1000 Tick×1シード×2条件の短時間テスト成功
2. CSVスキーマ・初期遺伝子分布・単調な累積カウンタの確認
3. 20シード×B/Fの40ランを軽量出力で実施
4. 既存F−B結果との結合20/20と品質検証
5. 因果推論は行わず、未解決の交絡と再現性の制約を記録

## 状態
実装完了、Rust実機検証待ち。自然選択の成立・ばらつきの原因特定は継続検証。

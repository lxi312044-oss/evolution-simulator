# Phase 07.2.15 — 繁殖条件・年齢構成・死亡原因の観測強化

## 目的
Phase 07.2.13–14で観測された3,000–6,000 Tickの無出生期間について、繁殖条件の未成立、年齢構成、年齢死/HP死の時系列を切り分ける。最終目的は毒耐性の自然選択の検証に戻ること。

## 方法
- Rustの既存`World.diagnostics`にある累積ゲートカウンタを100 Tick単位で差分出力。既存のシミュレーション規則は変更しない。
- `age < reproduction_min_age`、`min_age <= age < 2*min_age`、`age >= 2*min_age`の年齢構成を観測時点に記録。
- B/F × 20シード、50,000 Tick。既存の40ランの**元CSVは共有されていない**ため、新しい診断ログはローカル再実行で取得する。
- 解析は0–3,000、3,000–6,000、6,000–10,000、10,000–50,000 Tickを事前定義した区間として集計。

## 解釈上の制約
- ゲートカウンタは個体×Tick単位であり、ユニーク個体数ではない。
- ゲート成立は重複するため、不成立数を単純合計できない。
- すべてのゲート成立と出生は同一ではない（確率的な食料条件、資源、容量等）。
- `herbivore_age_deaths`/`herbivore_hp_deaths`は実装上の分類。毒・捕食・飢餓の因果的死因内訳ではない。
- Phase 07.2.14の集計のみからこれらの新しい観測項目を復元することはできない。

40ラン、20ペア、全ラン最終Tick 50,000、quality issues 0。実際の機構的原因の確定は別途判定。

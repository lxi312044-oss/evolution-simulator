# Phase 07.2.12.1 — 観測データの整合性修正

- 事象: seed12345 のB/Fのみ最終Tick=1000、残り38ランは50000。
- 原因: runnerが既存CSVの最終Tickを検査せずスキップし、解析もB/F同士の一致しか検査しなかった。
- 修正: runnerの既存CSV検証、再実行後の最終Tick検証、解析のexpected-ticks検証、期待seed全件の網羅性検査。
- 修復: seed12345のB/Fを`-Force`で50000Tick再実行する。
- 注意: 現時点でユーザー環境の再実行は未実施。修正後の40ラン整合性は未確認。
- 範囲: 観測と解析の整合性のみ。生態/遺伝/毒パラメータは不変。

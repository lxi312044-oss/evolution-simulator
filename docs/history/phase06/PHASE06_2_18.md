# Phase 06.2.18 — 肉食動物のエネルギー収支の切り分け

## 目的
草食動物が生態系全体に存在しても肉食動物が餓死する原因について、基礎代謝Eと移動Eの寄与を独立に比較する。繁殖・捕食・消化・移動AIの仕様は固定し、**代謝パラメータのみ**を変更する。

## 比較条件
| 条件 | 基礎代謝E/Tick | 移動E/距離 | 変更点 |
|---|---:|---:|---|
| control | 0.030 | 0.010 | 06.2.17基準 |
| basal-80 | 0.024 | 0.010 | 基礎代謝のみ80% |
| basal-60 | 0.018 | 0.010 | 基礎代謝のみ60% |
| movement-50 | 0.030 | 0.005 | 移動消費のみ50% |

5シード（12345～12349）×50,000 Tick×4条件＝20試行。`-Ticks 1000 -SeedCount 1` で短時間試験可。

## 実行
```powershell
cargo test --workspace
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\run_phase06218.ps1" -Ticks 1000 -SeedCount 1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\run_phase06218.ps1"
```

結果：`results/phase06218/{control,basal-80,basal-60,movement-50}/seed-<seed>.csv` と `summary.csv`。

## 分析時の注意
- `hunt_energy` は捕食によるE移転の累計。`energy_basal_spent` と `energy_movement_spent` は消費Eの累計。
- `energy_reproduction_spent` の扱いはコードで確認し、子へのエネルギー移転を熱消費と混同しない。
- 絶滅が早い条件は累計消費が小さくなり得るため、単純な累計値だけで効率を判断しない。絶滅Tick、出生・死亡、捕殺、活動Tick、個体Tick当たりの値も比較する。
- 生態系全体の草食動物数と肉食動物の近傍での遭遇率は別。代謝を下げても捕食AIの問題は残り得る。
- 自然絶滅は許容し、強制補充はしない。
- Rust/WASM・Web UIは変更せず、バッチ検証用設定とスクリプトを追加した。

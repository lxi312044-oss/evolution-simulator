# Phase 06.2.15 — Web / Batch alignment and carnivore statistics

- Both start from the same `config/phase06214-validation.json` (copied to `web/src/default-config.json`).
- Web displays carnivore population, hunts, births/deaths, search and target ticks, persistent search ticks, heading changes, earned energy, distance.
- Web can export **the exact active JSON** and import JSON to reset the world.
- Batch runner accepts `-ConfigFile` to run with an exported Web JSON, replacing only `seed` for each run.
- Web and batch use the same `sim-core::World` Rust implementation. The WASM and native builds can still differ due to floating-point/platform behavior; exact row-by-row parity must be verified rather than assumed.
- To compare exactly one seed, use `-SeedCount 1 -SeedStart 12345` and the exported JSON.

```powershell
cargo test --workspace
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_phase06215.ps1 -Ticks 1000 -SeedCount 1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_phase06215.ps1
wasm-pack build crates/sim-wasm --target web --out-dir ../../web/src/pkg
cd web
npm install
npm run dev
```

For a custom Web config, export JSON to the project root then run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_phase06215.ps1 -ConfigFile .\phase06215-seed12345.json -SeedCount 5
```

**Note:** Web log CSV and batch CSV have different column sets; compare overlapping snapshots (`tick`, populations, carnivore counters, E/N errors). Web logs use 100 Tick intervals.

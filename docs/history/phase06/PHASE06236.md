# Phase 06.2.36 — Web 遺伝型AI・統計出力

- Web起動時は `config/phase06235-genetic.json` を初期条件に採用。
- 条件セレクトで従来型（0）、待ち伏せ型（1）、遺伝型（4）を選択。選択時はリセット。
- 適用条件を画面に表示し、CSVに `phase`, `condition`, `movement_strategy` を追加。
- Rust `ecology_snapshot_json` の既存の `carnivore_ambush_gene_mean`, `carnivore_ambush_gene_variance` をWebに表示、CSVへ出力。
- 肉食動物が0の場合、画面表示は「絶滅」とし、CSVの平均・分散はRust既存仕様の0のまま。解析時は `carnivores > 0` の行だけを遺伝子分布に使うこと。
- 遺伝子継承回数、突然変異回数、学習の更新回数は今回未実装。肉食動物の学習そのものも未実装。
- 保存則・行動AIのRustロジックは変更していない。

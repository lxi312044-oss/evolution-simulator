# Phase 06.2.41 — 捕食追跡の診断

06.2.40の設定を維持し、肉食動物の行動に影響を与えない累積診断カウンターを追加します。

- `p41_visible_samples`: 非満腹状態で餌を選択した個体Tick数
- `p41_approach_samples`: 選択した同じ餌への距離が肉食動物の移動により縮まった個体Tick数
- `p41_retreat_samples`: 同じ餌への距離が増えた個体Tick数
- `p41_attack_reach_samples`: 移動直後に選択した餌が攻撃距離内にいた個体Tick数
- `p41_chase_basal_energy` / `p41_chase_movement_energy`: 餌選択中に消費した基礎・移動エネルギー
- `p41_starvation_with_visible_prey`: エネルギー死亡時に餌が視界内にいた件数

既存の `hunt_attempts`, `hunt_positive_energy`, `prey_in_attack_range`, `hunt_refuge_blocked`, `hunt_cooldown_blocked` と組み合わせて分析します。これらは個体Tick累積値であり、独立した追跡エピソードの成功率ではありません。草食動物が同Tickの後半に動く場合の距離変化は含みません。

## 実行

```powershell
cargo test --workspace
.\run_phase06241.ps1 -Ticks 1000 -SeedCount 1
.\run_phase06241.ps1
python .\analyze_phase06241.py
```

長期検証は50,000 Tick × 5 seeds × 3 modes。完了済みCSVはソースハッシュ・設定ハッシュ・最終Tick・行数・列数でスキップし、未完了は再実行します。

## 制限

個体別追跡履歴・追跡開始/中断イベント・最後の捕食からの経過Tick・草食動物の逃走/採食切替回数は未実装。今回の統計だけでは追跡の因果関係を断定できません。

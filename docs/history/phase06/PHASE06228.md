# Phase 06.2.28 — Carnivore body N and hunting-state comparison

Baseline: phase 06.2.27 streak-60 for herbivores, unchanged.

- `control`: predator body-N repair OFF, original feeding hysteresis.
- `body-n-repair`: move at most 0.02 N/tick from predator reserve to body (strictly conserved).
- `repair-hunting`: same repair plus feeding stop fraction 0.90 / resume fraction 0.40.

**Important architectural finding:** predator reproduction currently withdraws offspring body N from the *reserve*, unlike herbivores. Therefore predator body-N repair does **not** remove the same reproduction gate as the herbivore fix. It could even reduce reserve N available for births. The third condition adjusts predator hunting hunger/feeding hysteresis, not a reproduction satiety-streak (which does not exist for predators). Treat all effects as hypotheses until tested.

No species is artificially restored. N/E resource conservation is maintained through account transfers. Check for reduced reserve N and reproduction before adopting the repair.

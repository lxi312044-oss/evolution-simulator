# Phase 06.2.29 — 肉食動物の身体Nと繁殖資源の整合性

## 背景
06.2.28で身体N回復を有効化すると肉食動物の繁殖が0となった。肉食動物は子の身体Nを親の貯蔵Nから供給するため、無条件に貯蔵Nから身体Nへ移すと競合する。

## 4条件
- control: 06.2.28の基準。
- hunting-only: 身体N回復なし、捕食閾値のみ変更。
- repair-fixed: 身体N回復時に子1匹分の貯蔵N（offspring_body_nutrients + offspring_reserve_nutrients）を保護。
- repair-fixed-hunting: 上記保護と捕食閾値変更。

保護付き回復は `body_n_repair_per_tick=0.021` を実験用の識別値として用いる。実際の転送上限も0.021 N/Tick。今後は専用のboolean設定へ分離することを推奨。保存則に影響する資源生成は行わない。

## Web版

## 注意
この修正は繁殖に必要な貯蔵Nを保護する比較実験であり、肉食動物の長期生存を保証しない。50,000 Tick×5シードの結果で判定する。

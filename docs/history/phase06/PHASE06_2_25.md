# Phase 06.2.25 — 草食動物の身体N回復経路と繁殖条件の検証

## コード調査で判明した構造

- 摂食Nは植物のbodyから草食動物のstomachへ移転する。
- 消化Nはstomachからreserveへ移転する。
- しかし従来はreserveからbodyへ戻す経路が存在しない。
- 出生時の子のbody Nは親のbodyから移転される。したがって親のbody Nは繁殖ごとに減り、摂食だけでは回復しない。
- phase24のbody N充足率が低いのは、この構造と整合する。

## 変更内容

`body_n_repair_per_tick` を追加。デフォルト0で旧挙動を保持。0.02/0.05の条件ではreserve Nをbody Nへ保存則を維持して移転する。body Nは `max(initial_body_nutrients, offspring_body_nutrients)` を上限とする。これは暫定的な組織修復モデルであり、後のフェーズで成長・代謝との関係を再設計する可能性がある。

## 比較条件

- control: 修復0
- repair-002: 0.02 N/tick
- repair-005: 0.05 N/tick

3条件×5シード×50,000 tick。身体N不足・予備N保有・修復N・満腹継続時間・後期出生・植物個体数・肉食動物生存・N/E誤差を比較。

# Phase 06.2.32 — 行動戦略と逃走（実験版）

## 目的
肉食動物の探索行動（従来／待ち伏せ／長距離探索／低エネルギー時休息）と草食動物の簡易逃走を比較する。攻撃による反撃は未実装。

## 条件（各5シード×50,000 Tick）
- control: 06.2.31 control相当
- ambush: 獲物不在時80Tick休息・40Tick移動
- roaming: 獲物不在時の方向維持探索
- hybrid: 貯蔵E<15なら獲物不在時80Tick休息・40Tick探索、獲物を発見したら追跡
- hybrid-evasion: hybrid + 草食動物の捕食者察知逃走（55距離、1.4倍速）
- combined80: 06.2.31両方80%（草食動物絶滅の再現対照）
- combined80-evasion: combined80 + 草食動物逃走

草食動物は捕食者を検知すると植物探索より逃走を優先する。移動距離と消費Eは既存の保存則処理を使用し、無償の加速は行わない。捕食者の検知は現状全方位・遮蔽物なし。移動戦略は種全体で共通の設定であり、遺伝子ではない。

## 注意
最良条件はまだ未確定。肉食動物が50,000Tickまで生存することを保証しない。捕食者の行動戦略は獲物発見時には従来の追跡に戻る。逃走の有無は同じ乱数シードで比較するが、行動分岐により以後の乱数系列は変化し得る。

# Phase 06.2.38 — genetic behavior observation and safe batch reruns

- `run_phase06238.ps1`: skips completed matching CSVs using configuration, tick, interval and source-code SHA256 hashes; incomplete runs are regenerated using temporary files and only replace results after validation. `-Force` reruns all.
- `analyze_phase06238.py`: prints 5 gene-bin birth/death/parent reproduction/action counts and ambush fractions.
- Bins: [0,.2), [.2,.4), [.4,.6), [.6,.8), [.8,1]. Counts are cumulative, not independent per-snapshot values.
- Ambush and search choices are counted **only** while prey is not visible and predator is not satiated; chasing and satiated resting are excluded. The gene affects only strategy 4.
- Births are grouped by offspring gene; parent reproduction events by parent gene; deaths by deceased gene. Mutation counts are nonzero changes, not independent mutation probability draws.
- The bin-level statistics alone cannot establish natural selection or individual reproductive success; compare behavior fractions and survival exposure first.
- To test: `cargo test --workspace`; short run `./run_phase06238.ps1 -Ticks 1000 -SeedCount 1`; long run `./run_phase06238.ps1`; analysis `python analyze_phase06238.py`.

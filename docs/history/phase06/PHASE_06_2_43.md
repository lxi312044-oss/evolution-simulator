# Phase 06.2.43 — Genetic-only baseline and individual diagnostics

## Purpose

Phase 07に進む前に、毒なし生態系の再現可能な基準状態を確立する。**生態系の意思決定、移動、繁殖、捕食、RNG、資源移転は変更しない。**

## Changes

- 標準バッチは `genetic` のみ。`run_phase06243.ps1` は5シード×50,000 Tickを実行する。必要なら `-Modes fixed,ambush` と指定可能（その場合は対応する `config/phase06243-*.json` が必要）。
- `.life.csv` に親ID（`parent_id_index`, `parent_id_generation`）を追加。初期個体は空欄。IDは `(index,generation)` の組で扱う。
- `.life.csv` に同じ獲物を連続して認識したときのTick間相対距離増減（`relative_closer`, `relative_farther`, `relative_unchanged`）を追加。草食動物の移動と肉食動物の前Tick移動を含むが、ターゲット変更時は比較しない。
- 06.2.41の `retreat_ticks` は**肉食動物自身の移動直後の距離**を測る旧定義のまま残し、意味の異なる新カウンターと混同しない。
- `low_energy_visible_ticks`、`longest_no_positive_attack_ticks` を追加。後者は初回捕食以前を含まないため、出生からの最長飢餓間隔ではない。
- 通常の集計CSVは従来の240列を維持。新しい項目は `.life.csv` にのみ記録。
- READMEにPhase 07移行判断・合格条件・開発順序を保存。

## Run (PowerShell, project root)

```powershell
cargo test --workspace
.\run_phase06243.ps1 -Ticks 1000 -SeedCount 1
python .\analyze_phase06243.py
.\run_phase06243.ps1
python .\analyze_phase06243.py
```

Web版は引き続き同じ設定JSONを読み込んで視覚観察する。定量評価はバッチを基準にする。`config/phase06243-genetic.json` を元に各SeedのJSONが `results/phase06243/genetic` に保存される。

## Interpretation limits

- `.life.csv` は死亡または終了時の個体生涯累積値であり、独立した狩猟エピソードではない。
- 親が生存中に終了した場合や寿命等の条件により、系譜を完全に復元できない場合がある。親子関係は記録するが、完全な系統樹分析は別途必要。
- `bite_energy_received` と `digestion_received` は単純加算しない（二重計上のおそれ）。
- 生存個体は50,000 Tickで右打ち切り。生存/死亡の比較は活動期間で補正し、因果推論と混同しない。
- 本フェーズのRust/Windows PowerShell実行検証はユーザー環境で行う。異常時は短時間ログを共有する。

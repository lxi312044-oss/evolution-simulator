# フェーズ06.2.31：肉食動物のエネルギー消費の要因分離

06.2.30の`digestion-adjusted`（消化2倍、繁殖胃条件25%）を基準とし、肉食動物の基礎代謝と移動コストのみを変える。草食動物の満腹継続時間は60 Tickに固定。

|条件|基礎代謝 E/Tick|移動 E/距離|
|---|---:|---:|
|control|0.018|0.010|
|basal-80|0.0144|0.010|
|movement-80|0.018|0.008|
|combined-80|0.0144|0.008|

全条件5シード×50,000 Tickで比較する。捕食・繁殖・死亡・植物・草食動物・N/E保存則を評価。**今回の実装はエネルギー収支の要因分離であり、行動AI自体は変更しない。**

## 行動パターンの今後の設計

待ち伏せ型：視界内に餌がいないとき、一定時間静止して代謝を節約し、接近した獲物を追う。長距離探索型：一定方向へ移動して餌密度の高い領域を探し、移動コストと遭遇率をトレードオフ。ハイブリッド型：身体Eと周辺餌密度に応じて切り替える。次の段階で各パターンを遺伝可能な行動特性に拡張できるようにする。

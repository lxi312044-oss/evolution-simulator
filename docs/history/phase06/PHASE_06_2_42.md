# Phase 06.2.42 — 個体別の狩猟・エネルギー診断とWeb操作改善

## 変更点
- Rust: 肉食動物ごとに視認・接近・後退・攻撃範囲・攻撃回数・獲得E・消化E・基礎代謝・移動消費・繁殖コスト・最後の正のエネルギー獲得Tickを累積記録。判断・RNG・資源移転は変更しない。
- バッチ: 既存の240列CSVに加えて、`seed-N.csv.life.csv` を出力。1行=死亡個体、または最終Tick生存個体。`id_index` と `id_generation` で識別。
- PowerShell: 完了済みCSVとlife.csvが揃った場合のみスキップ。
- Web: +100 Tickと再生×1/×2/×4、JSON入出力ボタン有効化。

## 制限
- エピソード単位の追跡（開始・中断の独立イベント）は未実装。個体の生涯累積統計である。
- `bite_energy_received` は捕食による獲得（胃に入るEを含む）であり、`digestion_received` と単純加算しないこと（二重計上）。
- `reproduction_energy_spent` は子へのE移転と繁殖熱を含む。`basal_spent`/`movement_spent` は消費として計上。
- 生存個体は観測打ち切りなので死亡個体と単純な寿命比較をしない。
- Webの再生速度は描画フレームと実行性能に依存する。高速実行で完全な実時間倍率は保証しない。
- 06.2.41と同じ生態系設定で比較。新たな行動変更は加えていない。

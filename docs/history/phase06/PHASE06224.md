# Phase 06.2.24 — Plant recovery / herbivore reproduction diagnostics

## Goal
Determine why surviving herbivores do not reproduce after plants recover. No artificial spawning, extinction prevention, or direct reproduction gate changes.

## Conditions
- control: unchanged phase 06.2.23 control
- feeding-110: feeding N per tick ×1.10
- feeding-120: same as phase 06.2.23 feeding-120

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_phase06224.ps1`

## New CSV fields
`phase24_repro_samples` and each `phase24_repro_*_ready` count independently satisfied gates at reproduction evaluation time; `phase24_repro_ready_all` means all deterministic gates passed, but does NOT include probabilistic local-food gate or population capacity. `phase24_repro_local_plant_*` aggregates nearby plant count and resource balances (body N, reserve E) over animal-tick samples. These counters are cumulative: compute differences between adjacent CSV samples and sum over windows 0–4000, 4000–8000, 8000–15000, 15000–30000, 30000–50000. Per-animal-tick averages require dividing by differences in `phase24_repro_samples`; do not interpret as distinct individuals.

## Caveats
Plant-local scan is diagnostic-only and O(herbivores × plants) per tick, so it can be slow. Existing resource conservation and all behavior remain unchanged for control/feeding-120. Feeding-110 alters only feeding N ceiling. Do not conclude causation from cumulative averages alone.

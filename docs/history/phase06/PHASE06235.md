# Phase 06.2.35 — Predator behavioral inheritance (experimental)

- New `Carnivore.ambush_gene` in [0,1], initialized deterministically from entity ID without changing legacy RNG draws.
- `movement_strategy=4` enables per-individual rest/explore schedules. Higher gene means longer waiting.
- Offspring inherit parent trait with uniform mutation in ±0.06, bounded [0,1].
- Existing modes 0–3 remain unchanged except added read-only trait storage.
- `behavior_genetics_snapshot()` includes predator ambush mean and variance; the existing CSV exporter is not extended by this prototype.
- `phase06235-fixed.json`, `phase06235-ambush.json`, `phase06235-genetic.json` are comparison configurations.
- IMPORTANT: This is **genetic selection**, not learned policy optimization. No lifetime adaptation or genome-fitness tracking yet.
- Rust tests, WASM build, and long-run behavior are not verified in this environment.

# Phase 06.2.14 — Web の肉食動物探索を草食動物方式へ統一

- `web/src/default-config.json` の肉食動物を初期4体、`enabled=true`、`persistent_search_enabled=true` に変更。以前はWeb側が `enabled=false` かつ0体であり、06.2.13のバッチ設定がWebには自動適用されていなかった。
- 獲物が視界外の場合は草食動物と同じ30～100 Tickの探索方向保持と壁反射を採用。方向変更は探索期間終了時のみ。
- 06.2.13の比較用JSONは再現性のため保持。旧方式は `persistent_search_enabled=false` で比較可能。
- 獲物の追跡は引き続き毎Tick最寄りの草食動物を選択する。複数の獲物が交差すると向きが急変する場合があり、完全な平滑化は今後の課題。
- 既存のN/E移転・消化・繁殖ロジックは変更していない。

## ブラウザ反映手順

```powershell
cargo test --workspace
wasm-pack build crates/sim-wasm --target web --out-dir ../../web/src/pkg
cd web
npm install
npm run dev
```

Viteを再起動し、ブラウザを再読み込みした後、シミュレーションをリセットしてください。Webの初期設定に肉食動物4体が含まれます。

**注意:** この変更ではブラウザ表示上の探索を改善することが主目的です。生存率や共存率は未検証です。Rustのコンパイルは生成環境では実行できません。

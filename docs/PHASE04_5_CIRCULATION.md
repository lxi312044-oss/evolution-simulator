# フェーズ04.5：植物の資源循環・繁殖条件の比較

## 目的
04.4の診断で、植物が増加した後に土壌Nが不足し、寿命死・捕食に出生が追いつかない現象を確認。**パラメータ比較で仮説を検証する**。安定共存を保証するものではない。

## 実装
- `mineralization_rate`: 同一セルの有機物N→土壌N。物質の新規生成なし。
- `soil_diffusion_rate`: 1 Tickで各セルの土壌Nの指定割合を上下左右の隣接セルに均等配分。各セルの拠出合計は拡散率以下。トーラス接続なし。初期スナップショットに基づく転送。
- `growth_per_tick`, `nutrient_uptake_max`, `seed_probability`, `seed_dispersal_radius`, `seed_cooldown_ticks` は既存の物質・エネルギー制約のままUIで比較可能。
- `soil_diffused_n` は土壌間で移動したNの累積量であり、外部からの供給量ではない。
- 既存の100 Tick間隔CSVと資源保存チェックを維持。

## 試験設定（仮説検証用）
| 項目 | 回復重視（04.4） | 循環改善（04.5） |
|---|---:|---:|
| 成長 | 0.009 | 0.009 |
| 吸収上限 | 0.3 | 0.3 |
| 種子確率 | 0.65 | 0.65 |
| 無機化率 | 0.002 | 0.012 |
| 土壌拡散率 | 0 | 0.08 |
| 散布半径 | 70 | 110 |
| 種子クールダウン | 100 | 100 |
| 摂食上限 | 0.35 | 0.35 |

## 検証手順
1. `cargo test --workspace` とWASMビルドを実施。
2. 回復重視設定で7,000 Tickまで実行してCSV出力。
3. 循環改善設定で同じシード・Tickまで実行してCSV出力。
4. Tick 1,000〜5,000の植物数、土壌N、土壌枯渇セル、種子失敗、無機化N、拡散N、総N誤差を比較。
5. 改善しなければパラメータを一つずつ変更して要因を分離。

## 制限
- 草食動物の繁殖はフェーズ05で実装予定。現段階では長期的な動物個体群の維持は不可。
- 本フェーズは生態系の資源保存とパラメータ比較を目的とする。土壌の物理モデルは簡略化している。
- 実機テスト・ブラウザ検証は利用者環境で実施予定。

# フェーズ05：草食動物の繁殖・遺伝・突然変異

## 実装済み
- 単為生殖：成体年齢・HP・E・クールダウン条件を満たす親から子を生成。
- 子の体N・貯蔵N・Eは親の口座から移動。繁殖作業Eは熱として計上。資源を新規生成しない。
- 親のHP・速度・視界を子に継承し、各遺伝子に独立5%確率の倍率変異（初期値±10%）。範囲を制限。
- 子は年齢0、親由来の寿命に変動を加え、繁殖クールダウンを持つ。
- 既存の100 Tick CSVに草食動物出生・繁殖試行・資源不足・個体数上限・突然変異の累積値と差分を追加。
- 同一シードの決定論、N/E保存則、繁殖無効のテストを追加。

## 注意・検証待ち
- 親の体Nから子へ移転するため親の体格は消耗する。現段階で成体の体N回復処理はないため繁殖回数に上限が生じる。
- 子の成長（幼体から成体への段階的な成長・体NによるHP変化）は次の改良候補。現状は成体HPの75%で出生。
- 生態系の長期安定性は未確認。複数シードで7000～20000 Tickの比較が必要。
- 実行環境で cargo test / wasm-pack / ブラウザ動作の確認を行うこと。

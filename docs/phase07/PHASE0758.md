# Phase 07.5.8 毒タイプ別の選択圧・適応度の因果分析に向けた診断

## 最終目的
毒A・Bそれぞれの耐性遺伝子が曝露に応じた生存・繁殖上の優位性を持ち、親子遺伝と世代間変化を通じて自然選択により進化することを実証する。

## 変更範囲
- Herbivore にタイプ別生涯曝露量 `lifetime_typed_dose` を追加。摂食時の実際の摂取量に基づき加算。
- 既存の毒負荷・毒ダメージ・遺伝・繁殖・資源会計は変更しない。
- 観測exampleで個体ごとの死亡時点・各サンプリング時点の耐性、累積曝露、年齢、繁殖数を記録。
- A優勢/B優勢/均等 × 2seed、6ラン。条件間の毒パラメータは固定。

## 解析と限界
`selection_strata.csv` は死亡個体の曝露有無・耐性上下で平均繁殖数と寿命を比較する**探索的な観察集計**。曝露量と年齢が共に増えること、死者のみを集計する生存者バイアス、初期耐性分布、毒以外の飢餓・捕食などを統制できない。因果効果を断定してはいけない。因果実証には同じ環境・同じ初期状態で耐性防御のみを操作した介入比較、世代別遺伝子頻度・選択差の確認が必要。

## 合格条件
1. Rust workspaceテストとPhase07.3.3旧版回帰がPASS。
2. 6ランすべてで `*.individuals.csv`, `*.types.csv`, `*.births.csv`, `*.outcomes.csv` を出力。
3. `selection_strata.csv` で曝露別・耐性別の寿命・繁殖数を比較可能。
4. **遺伝的進化の実証は別判定**。観測CSVが出ただけで進化成立としない。

- 検証待ち：Windows Rust実行・旧版回帰・6ラン
- 継続観察：曝露量と年齢の交絡、死亡個体のみの選択バイアス
- 未着手：同条件の介入実験と遺伝子頻度の世代推移による因果実証

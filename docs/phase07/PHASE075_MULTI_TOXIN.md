# Phase 07.5 複数毒と種別耐性 — 第1実装単位

## 目的
毒タイプごとに独立した負荷・閾値・除去率・耐性を扱う決定的な生理計算を追加する。

## 今回の変更範囲
- `TypedToxinState`、`TypedToxinParameters`、`advance_typed_toxin`、`advance_toxin_set` を追加。
- 毒IDの重複・並び順・不一致、無効な値を拒否。
- 旧型0と同一の計算順序・丸めを検証するテスト4件。
- 既存シミュレーションの生態・乱数・繁殖・資源計算は変更しない。

## 未実装（Phase 07.5 の完了条件）
- 植物個体への毒タイプ遺伝子と突然変異の付与。
- 草食個体への複数毒負荷と毒タイプ別耐性遺伝子の保持・遺伝・変異。
- 摂食によるタイプ別暴露の接続、種別耐性維持コストの資源勘定。
- 世代別の耐性頻度、選択差、親子相関、適応度のCSV。
- 複数毒有効時の長期実験と、旧版10,000Tick回帰比較。

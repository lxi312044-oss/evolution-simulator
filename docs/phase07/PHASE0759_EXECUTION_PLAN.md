## 評価項目（解析着手前に固定）

1. 既存types/設定検査に加え、births・outcomes・individualsのID、タイプ間対応、Tick、有限値、イベント件数と個体群収支を照合する。
2. 親子関係から創始個体を深度0、子を親+1とした生物学的世代深度を復元する。EntityIdのgenerationはスロット再利用番号なので世代とみなさない。
3. 毒タイプ別に世代深度ごとの出生時耐性、親耐性、親子差、変異観測割合、記録された子の出生数を集計する。
4. 個体別に出生時耐性、出生Tick、終端の曝露・繁殖観測、死亡/最終生存を集計。創始個体は出生時点が不明なので出生個体と分ける。出生1000Tickコホート・世代深度・毒タイプ別に記述する。
5. 同seed/同環境/同世代深度/同毒タイプでON−OFF差を提示。深度が存在しない群や絶滅時耐性は欠測とし、0で埋めない。個体数と出生数を毒タイプ間で二重加算しない。
6. 死亡時CSVは前Tickのスナップショットなので、最終Tickの摂取・繁殖は欠落し得る。累積曝露は死亡個体で下限値、死亡時successful_birthsより出生イベントからの子数を優先する。死亡原因や毒の因果効果を推定しない。
7. 2seedを個体数で水増しして有意差を主張しない。出生コホートや世代別の差も記述的比較であり、年齢・観測時間・生存者選択・浮動を除去した因果推論とはしない。

## 判定

技術判定は全Rustテスト・旧版回帰・12ラン・CSV品質の結果から行う。研究判定はタイプ別結果の方向・seed間差・代替説明・観測限界を明示し、進化実証未達の場合は継続観察/検証待ちとする。期待する方向が出るよう条件を事後調整しない。

# Phase 07.3.4 — 共通毒システムの回帰・長期安定性検証

## 目的
Phase 07.3.2/07.3.3で導入した毒の共通計算と共通データ型が、既存の毒耐性進化シミュレーションに退行を生じさせないことを検証する。

## 変更範囲
- `tools/verify_phase0734.ps1`: 固定ベースライン回帰と同一seedの長期実行を自動化。
- `tools/analyze_phase0734.py`: CSVの時系列・有限性・非負性・耐性階級整合性・同一seed再現性を確認。
- READMEと本書。**Rustモデル・乱数・Web実装・既存ベースラインは変更しない**。

## 合格条件
1. Phase 07.3.3の`cargo test --workspace`と10,000Tick回帰検証に合格。
2. seed12345・30,000Tick・100Tick間隔を2回実行し、資源・繁殖CSVのSHA-256が完全一致。
3. 記録された資源量・毒量・毒HP損傷が有限かつ非負（丸め誤差1e-6許容）。耐性階級の合計が草食個体数と一致。
4. 実行結果を`results/phase0734/REPORT.json`に保存し、実行環境と限界を記録。

## 実行方法
プロジェクトルートで：

```powershell
powershell.exe -ExecutionPolicy Bypass -File ".\tools\verify_phase0734.ps1"

```

実行時間を減らすため、初回は30,000Tick×2回の単一seedとする。異常時のみ追加seed/長期実験を検討。

## 注意事項
- 資源・繁殖CSVには生態系全体のエネルギー/栄養総勘定が含まれない。CSVのみで保存則を証明したとはみなさず、既存のRust資源保存テストで補完する。
- 100TickごとのCSVで、サンプル間の一時的なNaN/Infを完全に否定することはできない。
- `toxin_dose_cumulative`等は生存個体の生涯累積値の集計であり、時系列単調増加を必須としない。
- 肉食動物の絶滅は「継続観察」。本CSVには肉食個体数がなく、別のWebログ等で確認する。
- `results/phase0732/verify`は旧回帰スクリプトの出力先。今回の新規長期検証は`results/phase0734/`へ出力する。

## 課題管理
- 解決済み: Phase 07.3.3（Rust62テスト・10,000Tick回帰・Web動作確認）。
- 検証待ち: Phase 07.3.4 Windows実行、30,000Tick再現性と数値安定性。
- 継続観察: 肉食動物の絶滅、毒耐性と繁殖適応度の関係。
- 先送り: 毒の個体差・毒生産コスト（Phase 07.4）、複数毒（07.5）、色学習と擬態（07.6以降）。

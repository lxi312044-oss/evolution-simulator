# Phase 07.3.2 — 毒生理計算の共通化

## 目的
種に依存しない純粋関数へ単一毒の計算を抽出し、現行の計算順と浮動小数の丸めを変えない。

## 実装
- `toxin::exposure_dose`: 摂食量から毒量を算出
- `toxin::advance_burden`: 排出→閾値→損傷→耐性軽減→f32丸め
- `toxin::resistance_upkeep`: 耐性維持費の算出
- 草食のHP更新、診断累積、資源台帳、繁殖と乱数消費は従来の呼出側に残す
- 植物の毒生成コスト、肉食の毒作用、毒の種類数は変更しない

1. `cargo test --workspace` が成功する。

# Phase 07.4.6 — 草食・肉食動物への毒形質の統合設計

> **現行の開発順序（2026-11-11）**：[5段階ロードマップ](../DEVELOPMENT_ROADMAP.md) の段階3で、毒・耐性基盤と色学習・判断機能を前提に動物毒を実装する。植物擬態の実証を先行必須条件とする旧依存は適用しない。本書の詳細設計は引き続きレビュー・承認対象であり、以下の当時の実装状態を現在のコードの証拠とはしない。

**状態：設計案（レビュー・承認待ち）。この版は動物の毒生成・伝播を実装しない。**

## 目的とロードマップ境界
植物で検証した有毒/無毒形質・生成コスト・診断の考え方を、草食・肉食へ適用するためのインターフェースと検証契約を固定する。旧フェーズ番号では08に対応する事前設計であり、現在は採用済み5段階ロードマップの段階3へ接続する。詳細設計の確定は必要だが、承認済み開発順序の再承認は要求しない。動物の擬態の研究実証は段階5で扱う。

## 現行実装の事実（Phase 07.4.5）
- `plants::Plant.produces_toxin: bool` は遺伝・変異し、生成コストは植物の reserve から熱へ計上される。
- `animals::HerbivoreGenes.toxin_resistance` は遺伝し、`Herbivore.toxin_load` が被毒量を保持する。草食は植物摂食時に毒を受ける。
- `animals::carnivore::Carnivore` は色・エネルギー・繁殖関連状態を持つが、毒生成遺伝子・毒負荷・耐性はまだ持たない。
- `toxin.rs` に `ToxinTypeId`, `ToxinProfile`, `ToxinBurden`, `ToxinResistance`, `ToxinProduction` がある。現在は LEGACY=0 の単一毒のみが稼働し、互換アダプタがある。
- 草食から肉食への摂食毒伝播は未実装。毒を持つ動物の体色を捕食者が学習する機能も未実装。

## データモデルの設計契約
毒生成 `production`、摂食による蓄積 `burden`、耐性 `resistance`、体色 `color` は別々の状態。生成可能であることは耐性を保証せず、摂食毒を蓄積しても生成遺伝子は変化しない。記憶は学習状態であり遺伝しない。

- 草食：既存 `toxin_load` と `toxin_resistance` を当面 authoritative とし、生成形質（有毒/無毒、将来の生成量）を追加する場合も既存フィールドの意味を変えない。
- 肉食：新規の生成形質、蓄積量、耐性を独立に設計。旧モードでは全て無効・負荷0で、既存挙動を維持。
- 生成量・生成費：生物種別の設定と遺伝子値を区別。エネルギーが不足したときの生成可否は、資源勘定に従う（負残高を許さない）。毒の「体内保有量」と「相手へ渡す量」は別に記録する。
- 色：既存の草食 `HerbivoreGenes.body_color` と肉食 `Carnivore.color` は毒形質から独立して遺伝/変異する。毒性に応じて色を強制設定しない。
- 毒種：07.5の複数毒化を阻害しないよう `ToxinTypeId` を保持。最初の動物毒統合では LEGACY=0 のみを許し、別毒種の混合規則は07.5で決定する。

## 食物連鎖の毒伝播仕様（将来実装時の提案）
1. 植物→草食：既存経路を基準とし、摂食量に比例する暴露を記録。旧設定では計算順・丸めを変えない。
2. 草食→肉食：**実際に摂食した量**に応じて、草食が生産した毒と摂食由来の残留毒のどちらを移すかを別々に定義する。二重計上を防ぐため、摂食時の体内毒量・移動量・残留量を記録する。
3. 肉食→上位捕食者：現行モデルに上位捕食者がいないため、API設計のみ。未実装の伝播を発生したものとして記録しない。
4. 毒生理：既存の `advance_burden` 相当の共通処理を使用し、耐性・解毒・HP損傷・生産費を独立計上。
5. 毒生成は熱へのエネルギー散逸を伴うが、毒の「単位」はエネルギー/栄養と同一ではない。資源保存の計算を毒単位で二重計上しない。

## 設定・互換性
将来の設定案（**この版のJSONには追加しない**）：`toxin.herbivore_production_enabled=false`, `toxin.carnivore_production_enabled=false`, `toxin.animal_transfer_enabled=false`。旧JSONをそのまま読める `serde(default)` と、既存の `deny_unknown_fields` の制約を両立させる。新規フラグはデフォルトOFF。旧モードの個体生成・乱数呼び出し順・tick更新順・CSVヘッダーを維持。新診断CSVは別ファイルにする。

## 必要な観測項目
種×有毒/無毒の生存数・出生・死亡、親子の生成形質・耐性、摂食毒暴露、草食→肉食移動毒量、毒生成エネルギー費、体内蓄積・解毒・HP損傷、捕食数、捕食者/被食者の体色。各経路で暴露と生成の寄与を別列に分離する。

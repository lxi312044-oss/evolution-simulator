# Phase 07.4.4 — 毒生産コストと植物の繁殖・生存メカニズムの切り分け

## 目的
Phase 07.4.3の9run（3seed×コスト3条件、10,000Tick）を再利用し、毒生産コストによる形質頻度変化を、出生、老齢死、被食死、草食動物個体数の観測指標に分解する。因果経路が特定できない場合は未確定と明記する。

## 変更範囲
- `tools/analyze_phase0744.py`：100Tick観測値を用いた植物延べ生存Tick近似、2,500Tick区間ごとの出生率・老齢死亡率・被食死亡率、形質別収支、同seed比較。
- `tools/test_phase0744.py`：人口収支と入力検証の単体テスト。
- `tools/run_phase0744.ps1`：Rust全テスト・旧版回帰・分析をまとめて実行。
- `results/phase0744/REPORT.json` と `WINDOWS.csv`：既存の9runから生成した暫定解析結果。
- シミュレーションのRust計算処理、毒生理、遺伝、RNG、Webは変更しない。

## 実行
プロジェクトルートで：

```powershell
powershell.exe -ExecutionPolicy Bypass -File ".\tools\run_phase0744.ps1"
```

旧版回帰がすでに完了した場合のみ：

```powershell
powershell.exe -ExecutionPolicy Bypass -File ".\tools\run_phase0744.ps1" -SkipRegression
```

既存結果だけを再分析する場合：

```powershell
python tools/analyze_phase0744.py --input results/phase0743 --output results/phase0744
```

## 合格条件
1. `cargo test --workspace` が失敗0件。
2. `python -m unittest discover -s tools -p 'test_phase0744.py'` が合格。
3. `verify_phase0733.ps1` が旧版回帰PASS。
4. 9run×4区間の形質別出生・死亡収支の差分が0、入力CSV検証に異常なし。
5. Web版の起動確認（Webコード変更なし）。
6. 分析結果に解釈の限界を記載し、植物エネルギー媒介経路は未確定として扱う。

## 既存9runからの暫定所見
- 36区間（9run×4）で形質別の出生・死亡の会計残差は0。
- 10,000Tick全体の単位植物Tickあたり出生率は、9条件中7条件で無毒植物が有毒植物より高い。
- 被食死亡率の形質差はseedとコストによって符号が変わる。
- 有毒率が上昇した条件でも、必ずしも有毒植物の出生率が高いわけではない。
- 草食動物数は捕食圧の間接指標であり、植物への接触・摂食回数そのものではない。

## 制約・次の課題
- 既存CSVの出生数には自然発芽が含まれ、遺伝的な親子繁殖成功率とは区別できない。
- 植物の個体別保有エネルギー、土壌栄養、形質別摂食試行は未記録。毒生産コスト→保有エネルギー→繁殖の直接経路は現時点で検証できない。
- 観測は100Tickごとであり、分母となる植物延べ生存Tickは台形近似。
- コスト変更後の世界の軌道は分岐するため、差分から直接経路だけを特定することはできない。
- 次の実装候補は、シミュレーションの状態を変更しない形質別エネルギー・親由来出生・捕食イベント観測の追加。診断追加後も旧版回帰を必須とする。

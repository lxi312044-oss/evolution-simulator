# Phase 07.5.7 毒タイプ別の選択圧・適応度の検証

## 最終目的
毒A/Bごとの遺伝的耐性について、曝露依存の生存・繁殖上の有利さと世代間伝達を実証する。生存数の増加は手段であり合格条件ではない。

## 変更範囲
- `initial_type0_fraction`（既定0.5）を追加。毒タイプ2種の初期植物と自然発芽植物のタイプ0割合を変更する。子の植物は親のタイプを遺伝し、既存の突然変異率を使用する。
- 毒の強度・作用・耐性・突然変異・植物毒生産コストは変更しない。
- 両タイプの耐性維持コスト倍率0.5を全条件で固定。毒Bだけを優遇しない。
- 3環境（80/20,20/80,50/50）×2seed = 6ランのパイロット。
- 出力は `.types.csv`, `.births.csv`, `.outcomes.csv`, `summary.csv`。

## 検証
`tools/verify_phase0757.ps1` による Rust 全テストと Phase07.3.3 固定回帰を要求。
`tools/run_phase0757.ps1` で6ラン。パイロット完了は自然選択の実証ではない。

## 合格条件と限界
- 旧版デフォルトで固定回帰が完全一致または規定のCSV行同値。
- 同seedで毒タイプの割合だけが異なる。初期・自然発芽植物は指定の割合に近づくが、植物繁殖・選択・突然変異で時間とともに変動する。
- 生存集団がゼロの場合、最終耐性平均は欠測として扱い、0への進化と解釈しない。
- 親子相関、耐性の時系列、タイプ別植物比率、負荷を比較する。
- 進化の最終実証には曝露個体別の生存率・繁殖成功率と選択差の追加検証が必要。6ランだけで因果や統計的再現性を断定しない。

## 課題
- 植物比率が実験中に大きく変動する場合は選択圧の維持方法を検討（検証待ち）。
- 個体別曝露と生存・繁殖成功率の直接リンクは未着手。
- 追加seedによる再現性は先送り（パイロット結果次第）。

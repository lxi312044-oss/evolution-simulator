# Phase 07.5.6 — 公平な耐性維持コストと遺伝的選択の再検証

## 最終目的（固定）
**毒タイプ別の耐性遺伝子が、毒曝露による生存・繁殖差を介して世代を越えて進化することを検証する。** 生存数増加のみでは合格としない。

## 変更範囲
`multi_type_resistance_upkeep_multiplier` (0..1, default 1) を追加。複数毒モードのときタイプ0および追加タイプの維持費合計に同じ倍率を適用する。タイプ1だけを優遇しない。既存の `additional_type_resistance_upkeep_multiplier` は互換性のため残し、実験では1に固定。単一毒モード・既定値は変更なし。毒ダメージ、耐性遺伝、突然変異、植物毒生産は変更なし。

注意：この倍率は**耐性維持のエネルギー負担**を変える。生存上の選択圧も変わるため、最小維持費が進化に最適とは限らない。0.25/0.5/1の探索比較であり、生物学的に正しい最適値の確定ではない。

## 実験設計
`tools/verify_phase0756.ps1`：全RustテストとPhase07.3.3固定回帰。
`tools/run_phase0756.ps1`：2 seed × 3公平コスト倍率 × 2耐性効果条件 = 12 run、各10,000 tick（既定）。
`protected`：耐性による毒負荷軽減あり（既存設定）。`no_protection`：`resistance_effectiveness=0` で防御効果のみ無効化。両条件で維持費と遺伝変異は残す。これは防御効果の反実仮想比較であり、毒作用なし条件とは異なる。
出力は各runの `.types.csv` `.births.csv` `.outcomes.csv` と `summary.csv`。各実験の生成JSONを保存して再現性を担保。

## 合格条件と保留条件
1. Rustテスト・旧版回帰PASS。既定値1.0で旧版一致。
2. 単一毒への影響なし、複数毒の維持費が倍率とともに単調変化。
3. 12runでタイプ別耐性平均・出生親子の相関・出生/死亡・曝露量を出力できる。
4. **進化成立の判定は別途**：各タイプで実際の毒曝露、十分な出生と世代交代、耐性の遺伝性、親の繁殖成功と耐性の関連、毒防御有無の差、seed間の再現性を合わせて確認。`summary.csv` の平均変化だけでは合格にしない。絶滅時の平均値0は進化的低下と解釈しない。
5. 2 seed はパイロットであり有意性・因果の最終結論は出さない。必要時のみ追加seed/長期runを計画する。

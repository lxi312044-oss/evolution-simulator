## 保存済み10,000Tick実験から確認できること

| seed | 初期毒分布 | 最終草食数 ON / OFF | 出生数の差 ON−OFF |
|---|---|---:|---:|
| 12345 | A80 | 0 / 0 | +92 |
| 12345 | B80 | 0 / 0 | +78 |
| 12345 | equal | 91 / 20 | +140 |
| 12346 | A80 | 0 / 3 | +67 |
| 12346 | B80 | 34 / 0 | +106 |
| 12346 | equal | 23 / 16 | +65 |

12ラン中6ランで草食が絶滅（ON/OFF各3）。ONでは6組すべて出生数が多いが、最終個体数が増えるとは限らない。絶滅の観測区間はseed12345のA80 ON=(8700,8800]、OFF=(7000,7100]、B80 ON=(8700,8800]、OFF=(8600,8700]、seed12346のA80 ON=(7800,7900]、B80 OFF=(8800,8900]。

両群が生存したequal条件の耐性変化ON−OFFは、seed12345でA=+0.01019439/B=+0.031713943、seed12346でA=−0.035211916/B=+0.007778709。Aの符号はseed間で逆であり、2seedだけで一般的な適応進化を実証できない。絶滅群を耐性ゼロとして比較しない。

# Phase 07.4.5 — 植物のエネルギー状態と親個体の繁殖成功率の直接観測

## 目的
毒生産コストが植物の保有エネルギー・繁殖準備状態・実際の種子散布成功にどう関係するかを、形質別に観測する。Phase 07.4の植物診断は本フェーズで一区切りとし、次は食物連鎖への共通毒形質の統合を優先する。

## 変更範囲
- 既存の毒生理・資源収支・RNG・植物繁殖条件を変更しない。
- 親形質別の種子散布試行数、資源不足数、成功数を診断カウンタへ追加。
- 形質別の保有エネルギー平均・最小・最大、成熟・クールダウン・資源条件をCSVに記録。
- 自然発芽は親の繁殖成功に含めない。子の形質が突然変異した場合も、成功は親の形質に帰属する。

## 標準検証
`powershell.exe -ExecutionPolicy Bypass -File ".\tools\run_phase0745.ps1"`

デフォルト: 3seed × 3コスト × 5000Tick、100Tick間隔。必要なら `-Ticks 10000` で延長。

## 合格条件
1. `cargo test --workspace` が全件合格。
2. Python分析テストが全件合格。
3. 旧版の10,000Tick資源・繁殖CSVがSHA256一致、個体履歴CSVがレコード一致。
4. 9runの `results/phase0745/REPORT.json` がPASS、欠測・非有限値・累積カウンタ逆行なし。
5. Web動作確認。

## 解釈上の制約
エネルギーはスナップショットであり、繁殖直前のエネルギーではない。成功/植物延べTickは比較指標であり、個体ごとの生涯繁殖成功率ではない。コスト変更により集団動態・捕食圧が変化するため、単独で因果経路を証明しない。
